**前置题目**：[1916. 统计为蚁群构筑房间的不同顺序](https://leetcode.cn/problems/count-ways-to-build-rooms-in-an-ant-colony/)，[我的题解](https://leetcode.cn/problems/count-ways-to-build-rooms-in-an-ant-colony/solutions/3055993/jian-dan-zuo-fa-pythonjavacgo-by-endless-rvtp/)。

本题要计算 $\textit{nums}$ 的合法排列个数。根据 1916 题的结论，求出每棵子树的大小 $\textit{size}[i]$，那么答案为

$$
\dfrac{n!}{\prod\limits_{i=0}^{n-1} \textit{size}[i]} - 1
$$

减一是因为本题必须重排 $\textit{nums}$，不能不变。

如何求出每棵子树的大小？

![lc1569.png](https://pic.leetcode.cn/1791336503-JShjln-lc1569.png)

为方便描述，下文用节点值作为节点的编号。设节点 $x$ 的左儿子是节点 $\ell$。考察满足 $\ell<v<x$ 的节点 $v$：

- 由于 $v<x$，所以 $v$ 在 $x$ 的左子树中。
- 由于 $v>\ell$，所以 $v$ 在 $\ell$ 的右子树中。

因此，$\ell$ 的右子树恰好包含了 $(\ell,x)$ 中的每个整数（注意本题 $\textit{nums}$ 是排列）。

$\textit{nums}$ 是插入节点的顺序，父节点一定出现在子节点的前面。那么倒着遍历 $\textit{nums}$，当我们遍历到节点 $x$ 时，$x$ 的左右儿子一定遍历过。为了快速找到左右儿子，想象有一个有序集合 $S = \{1,2,\ldots,n\}$，我们可以在遍历到节点 $i$ 时，把 $i$ 的左右儿子从 $S$ 中删除掉。按照这一规则，遍历到节点 $x$ 时，在 $(\ell,x)$ 中的节点都已被删除，所以 $S$ 中的小于 $x$ 的最大值就是 $\ell$。对于右儿子同理，找 $S$ 中的大于 $x$ 的最小值。

代码实现时，用双向链表（用数组维护前驱后继）就能维护 $S$ 中的删除操作。遍历到 $x$ 时，$x$ 的前驱即左儿子，后继即右儿子。

```py [sol-Python3]
class Solution:
    def numOfWays(self, nums: list[int]) -> int:
        MOD = 1_000_000_007
        n = len(nums)

        # 0 和 n+1 作为哨兵节点
        prev = list(range(-1, n + 1))  # 双向链表的前驱 prev[i] = i - 1
        next = list(range(1, n + 3))   # 双向链表的后继 next[i] = i + 1
        size = [0] * (n + 2)  # 子树大小（节点个数）
        prod = 1  # 分母

        # 自底向上，计算每棵子树的大小
        for x in reversed(nums):
            size[x] = 1

            # x 左右两侧最近的未被删除节点，即为 x 的左右儿子
            left = prev[x]
            if size[left] > 0:
                # 加上左子树的大小
                size[x] += size[left]
                # 删除 left：在 left 的前一个节点与 x 之间建立双向链接
                pl = prev[left]
                prev[x] = pl
                next[pl] = x

            right = next[x]
            if size[right] > 0:
                # 加上右子树的大小
                size[x] += size[right]
                # 删除 right：在 right 的下一个节点与 x 之间建立双向链接
                nr = next[right]
                prev[nr] = x
                next[x] = nr

            prod = prod * size[x] % MOD

        # 计算分子 n!
        fac = 1
        for i in range(2, n + 1):
            fac = fac * i % MOD

        return (fac * pow(prod, -1, MOD) - 1) % MOD
```

class Solution {
    private static final int MOD = 1_000_000_007;

    public int numOfWays(int[] nums) {
        // 0 和 n+1 作为哨兵节点
        int n = nums.length;
        int[] prev = new int[n + 2]; // 双向链表的前驱
        int[] next = new int[n + 2]; // 双向链表的后继
        int[] size = new int[n + 2]; // 子树大小（节点个数）
        for (int i = 0; i < n + 2; i++) {
            prev[i] = i - 1;
            next[i] = i + 1;

        long fac = 1; // 分子
        long prod = 1; // 分母

        // 自底向上，计算每棵子树的大小
        for (int i = n - 1; i >= 0; i--) {
            fac = fac * (i + 1) % MOD;

            int x = nums[i];
            size[x] = 1;

                // 加上左子树的大小
                size[x] += size[left];

                prev[x] = pl;
                next[pl] = x;
            }

            int right = next[x];
            if (size[right] > 0) {
                // 加上右子树的大小
                size[x] += size[right];
                // 删除 right：在 right 的下一个节点与 x 之间建立双向链接
                int nr = next[right];
                prev[nr] = x;
                next[x] = nr;
            }

        }

    }

    private long pow(long x, int n) {
        long res = 1;
        for (; n > 0; n /= 2) {
            if (n % 2 > 0) {
                res = res * x % MOD;
            }
            x = x * x % MOD;
        }
        return res;
    }
}

const MOD: i64 = 1_000_000_007;

impl Solution {
    pub fn num_of_ways(nums: Vec<i32>) -> i32 {
        // 0 和 n+1 作为哨兵节点
        let n = nums.len();
        let mut prev = vec![0; n + 2]; // 双向链表的前驱
        let mut next = vec![0; n + 2]; // 双向链表的后继
        let mut size = vec![0; n + 2]; // 子树大小（节点个数）
        for i in 0..n + 2 {
            prev[i] = i - 1;
            next[i] = i + 1;
        }
        let mut prod = 1; // 分母

        // 自底向上，计算每棵子树的大小
        for x in nums.into_iter().rev() {
            let x = x as usize;
            size[x] = 1;

            // x 左右两侧最近的未被删除节点，即为 x 的左右儿子
            let left = prev[x];
            if size[left] > 0 {
                // 加上左子树的大小
                size[x] += size[left];
                // 删除 left：在 left 的前一个节点与 x 之间建立双向链接
                let pl = prev[left];
                prev[x] = pl;
                next[pl] = x;
            }

            let right = next[x];
            if size[right] > 0 {
                // 加上右子树的大小
                size[x] += size[right];
                // 删除 right：在 right 的下一个节点与 x 之间建立双向链接
                let nr = next[right];
                prev[nr] = x;
                next[x] = nr;
            }

            prod = prod * size[x] as i64 % MOD;
        }

        // 计算分子 n!
        let mut fac = 1;
        for i in 2..n + 1 {
            fac = fac * i as i64 % MOD;
        }

        ((fac * Self::qpow(prod, MOD as i32 - 2) - 1 + MOD) % MOD) as _ // +MOD 保证结果非负
    }

    fn qpow(mut x: i64, mut n: i32) -> i64 {
        let mut res = 1;
        while n > 0 {
            if n % 2 > 0 {
                res = res * x % MOD;
            }
            x = x * x % MOD;
            n /= 2;
        }
        res
    }
}
