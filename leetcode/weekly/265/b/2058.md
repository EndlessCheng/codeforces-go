遍历链表的过程中，维护第一个临界点的位置 $\textit{first}$、上一个临界点的位置 $\textit{pre}$。

用当前临界点的位置减去 $\textit{pre}$，更新 $\textit{minDistance}$ 的最小值。

$\textit{maxDistance}$ 即最后一个临界点的位置（遍历结束后的 $\textit{pre}$）减去 $\textit{first}$。

> 注：题目保证链表至少有两个节点。

```py [sol-Python3]
class Solution:
    def nodesBetweenCriticalPoints(self, head: Optional[ListNode]) -> List[int]:
        first, pre = 0, -inf
        min_dis = inf
        a, b, c = head, head.next, head.next.next
        i = 1

        while c:
            if a.val < b.val > c.val or a.val > b.val < c.val:
                if first == 0:
                    first = i
                min_dis = min(min_dis, i - pre)
                pre = i
            a, b, c = b, c, c.next
            i += 1

        if first >= pre:  # 临界点少于两个
            return [-1, -1]
        return [min_dis, pre - first]
```

```java [sol-Java]
class Solution {
    public int[] nodesBetweenCriticalPoints(ListNode head) {
        int first = 0;
        int pre = Integer.MIN_VALUE / 2;
        int minDis = Integer.MAX_VALUE;
        ListNode a = head;
        ListNode b = head.next;
        ListNode c = head.next.next;

        for (int i = 1; c != null; i++) {
            if (a.val < b.val && b.val > c.val || a.val > b.val && b.val < c.val) {
                if (first == 0) {
                    first = i;
                }
                minDis = Math.min(minDis, i - pre);
                pre = i;
            }
            a = b;
            b = c;
            c = c.next;
        }

        if (first >= pre) { // 临界点少于两个
            return new int[]{-1, -1};
        }
        return new int[]{minDis, pre - first};
    }
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是链表的长度。
- 空间复杂度：$\mathcal{O}(1)$。
