**前置题目**：[303. 区域和检索 - 数组不可变](https://leetcode.cn/problems/range-sum-query-immutable/)。

类似前缀和，用**前缀积**可以计算任意子数组的乘积。本题要计算最后 $k$ 个数的乘积，这等价于用最后一个前缀积除以倒数第 $k+1$ 个前缀积。

但如果执行了 $\texttt{add}(0)$ 呢？

我们可以把前缀积数组**重置**为初始状态（只有一个 $1$），然后在 $\texttt{getProduct}$ 时判断：

- 如果前缀积数组长度 $\le k$，没有倒数第 $k+1$ 个前缀积，说明我们重置过，也就是最近 $k$ 个数包含 $0$，返回 $0$。
- 否则正常算，结果为最后一个前缀积除以倒数第 $k+1$ 个前缀积。

```py [sol-Python3]
class ProductOfNumbers:
    def __init__(self):
        self.p = [1]

    def add(self, num: int) -> None:
        if num != 0:
            self.p.append(self.p[-1] * num)
        else:
            self.p = [1]

    def getProduct(self, k: int) -> int:
        if len(self.p) <= k:
            return 0
        return self.p[-1] // self.p[-1 - k]
```

```java [sol-Java]
class ProductOfNumbers {
    private final List<Integer> p = new ArrayList<>();

    public ProductOfNumbers() {
        p.add(1);
    }

    public void add(int num) {
        if (num != 0) {
            p.add(p.getLast() * num);
        } else {
            p.clear();
            p.add(1);
        }
    }

    public int getProduct(int k) {
        int n = p.size();
        if (n <= k) {
            return 0;
        }
        return p.getLast() / p.get(n - 1 - k);
    }
}
```

```cpp [sol-C++]
class ProductOfNumbers {
    vector<int> p = {1};

public:
    ProductOfNumbers() {}

    void add(int num) {
        if (num != 0) {
            p.push_back(p.back() * num);
        } else {
            p = {1};
        }
    }

    int getProduct(int k) {
        int n = p.size();
        if (n <= k) {
            return 0;
        }
        return p[n - 1] / p[n - 1 - k];
    }
};
```

```go [sol-Go]
type ProductOfNumbers []int

func Constructor() ProductOfNumbers {
	return []int{1}
}

func (p *ProductOfNumbers) Add(num int) {
	if num != 0 {
		*p = append(*p, (*p)[len(*p)-1]*num)
	} else {
		*p = []int{1}
	}
}

func (p *ProductOfNumbers) GetProduct(k int) int {
	n := len(*p)
	if n <= k {
		return 0
	}
	return (*p)[n-1] / (*p)[n-1-k]
}
```

#### 复杂度分析

- 时间复杂度：所有操作均为 $\mathcal{O}(1)$。
- 空间复杂度：$\mathcal{O}(q)$，其中 $q$ 为 $\textit{add}$ 的次数。
