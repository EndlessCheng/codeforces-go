## 方法一：排序

由于 $\textit{nums}$ 中的数都是正整数，所以 $\textit{nums}[i]$ 和 $\textit{nums}[j]$ 都越大越好。选 $\textit{nums}$ 中最大的两个数作为 $\textit{nums}[i]$ 和 $\textit{nums}[j]$。

```py [sol-Python3]
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        nums.sort()
        return (nums[-1] - 1) * (nums[-2] - 1)
```

```java [sol-Java]

    public int maxProduct(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        return (nums[n - 1] - 1) * (nums[n - 2] - 1);
    }
}
```

```cpp [sol-C++]

public:
    int maxProduct(vector<int>& nums) {
        ranges::sort(nums, greater());
        return (nums[0] - 1) * (nums[1] - 1);
    }
};
```


#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{nums}$ 的长度。瓶颈在排序上。
- 空间复杂度：$\mathcal{O}(1)$。忽略排序的栈开销。

## 方法二：维护最大次大

```py [sol-Python3]
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        max1 = max2 = 0
        for x in nums:
            if x > max1:
                max2 = max1
                max1 = x
            elif x > max2:
                max2 = x
        return (max1 - 1) * (max2 - 1)
```

## 方法三：枚举右维护左

暴力做法是枚举所有的下标对 $(i,j)$，其中 $0\le i<j<n$。

枚举 $j$，我们需要知道左边 $\textit{nums}[i]$ 的最大值。这可以用一个变量维护。

```py [sol-Python3]
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        ans = mx = 0
        for x in nums:
            ans = max(ans, (mx - 1) * (x - 1))
            mx = max(mx, x)
        return ans
```

```java [sol-Java]

            mx = Math.max(mx, x);
        }
        return ans;
    }
}
```
