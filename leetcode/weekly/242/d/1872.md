## 一、寻找子问题

设 Alice 的最终得分为 $A$，Bob 的最终得分为 $B$。

Alice 需要最大化 $A-B$，Bob 需要最小化 $A-B$（或者说最大化 $B-A$）。

也就是说，每个玩家都需要**最大化自己的得分减去对手的得分**。

为方便描述，下文把 $\textit{stones}$ 简记为 $a$。

看示例 1，$a = [-1,2,-3,4,-5]$。枚举 Alice 在第一回合移除的石子（至少移除两个）：

- 移除 $-1,2$，新石子的值为 $1$。接下来需要解决的问题是：剩余石子为 $a' = [1,-3,4,-5]$，Bob（现在是先手）的得分减去 Alice（现在是后手）的得分最大是多少。
- 移除 $-1,2,-3$，新石子的值为 $-2$。接下来需要解决的问题是：剩余石子为 $a' = [-2,4,-5]$，Bob（现在是先手）的得分减去 Alice（现在是后手）的得分最大是多少。
- 移除 $-1,2,-3,4$，新石子的值为 $2$。接下来需要解决的问题是：剩余石子为 $a' = [2,-5]$，Bob（现在是先手）的得分减去 Alice（现在是后手）的得分最大是多少。
- 移除 $-1,2,-3,4,-5$，新石子的值为 $-3$。接下来需要解决的问题是：剩余石子为 $a' = [-3]$，Bob（现在是先手）的得分减去 Alice（现在是后手）的得分最大是多少。

我们需要解决的子问题，都是**最大化先手的得分减去后手的得分**，都是**和原问题相似的、规模更小的子问题**，所以可以用**递归**解决。

虽然我们找到了子问题，但是，**原问题和子问题的关系**是什么？怎么利用子问题的结果，算出原问题的答案？

## 二、状态定义与状态转移方程

设 $S_{i} = \sum\limits_{k=0}^{i} a[k]$。

根据上面的讨论，定义 $\textit{dfs}(i)$ 表示在剩余石子为 $S_{i-1},a[i],a[i+1],\ldots,a[n-1]$ 的情况下，先手得分减去后手得分的最大值。

例如 $a = [-1,2,-3,4,-5]$。在第一回合，如果 Alice 移除 $-1,2$，那么 Alice 的得分增加

$$
S_1 = -1 + 2 = 1
$$

子问题为：对于 $a' = [1,-3,4,-5]$，Bob 如何操作，可以最大化「Bob 的得分减去 Alice 的得分」。注意这里的得分都是在 $a'$ 上的得分。

对于 $a'$，设 Bob 的得分为 $B'$，Alice 的得分为 $A'$，那么子问题可以表示为

$$
\textit{dfs}(2) = B'-A'
$$

我们要计算的原问题可以表示为

$$
\textit{dfs}(0)=A-B
$$

二者的关系是什么？

由于 $A = S_1 + A',\ B = B'$，所以有

$$
\textit{dfs}(0) = A-B = (S_1+A') - B' = S_1 - (B'-A') = S_1 - \textit{dfs}(2)
$$

即

$$
\textit{dfs}(0) = S_1 - \textit{dfs}(2)
$$

这样就找到了**原问题和子问题的关系**。

枚举先手移除的石子为 $S_{i-1}$ 以及 $a$ 的连续子数组 $[i,j]$，其中 $i\le j\le n-1$。那么新石子的值为 $S_{i-1} + \sum\limits_{k=i}^{j} a[k] = S_j$。问题变成在剩余石子为 $S_j,a[j+1],a[j+2],\ldots,a[n-1]$ 的情况下，先手得分减去后手得分的最大值，即 $\textit{dfs}(j+1)$。

取最大值，得到状态转移方程

$$
\textit{dfs}(i) = \max_{j=i}^{n-1} S_j - \textit{dfs}(j+1)
$$

上式是一个关于 $S_j - \textit{dfs}(j+1)$ 的**后缀最大值**。

当 $i\le n-2$ 时，我们可以把 $\max\limits_{j=i}^{n-1} S_j - \textit{dfs}(j+1)$ 中的 $j=i$ 这一项提出来，得到

$$
\begin{aligned}
\textit{dfs}(i) &= \max_{j=i}^{n-1} S_j - \textit{dfs}(j+1)         \\
     &= \max\left\{S_i - \textit{dfs}(i+1), \max_{j=i+1}^{n-1} S_j - \textit{dfs}(j+1)\right\}            \\
\end{aligned}
$$

根据状态转移方程，$\max\limits_{j=i+1}^{n-1} S_j - \textit{dfs}(j+1) = \textit{dfs}(i+1)$。

所以当 $i\le n-2$ 时，状态转移方程可以简化为

$$
\textit{dfs}(i) = \max(S_i - \textit{dfs}(i+1), \textit{dfs}(i+1))
$$

当 $i=n-1$ 时，剩余石子为 $S_{n-2}$ 和 $a[n-1]$，先手唯一做法是移除这两个石子，得到 $S_{n-2} + a[n-1] = S_{n-1}$ 分。

所以**递归边界**为

$$
\textit{dfs}(n-1) = S_{n-1}
$$

**递归入口**：$\textit{dfs}(1)$，这是原问题，也是答案。注意不能是 $\textit{dfs}(0)$，请仔细看 $\textit{dfs}$ 的定义，这会产生负数下标。

代码实现时，可以用递推式 $S_i = S_{i-1} + a[i]$ 计算 $S$ 数组。

#### 答疑

**问**：能不能把 $\textit{dfs}(n) = 0$ 作为递归边界？

**答**：如果定义 $\textit{dfs}(n) = 0$，那么根据状态转移方程，$\textit{dfs}(n-1) = \max(S_{n-1},0)$。如果 $S_{n-1} < 0$，那么 $\textit{dfs}(n-1) = 0$，与实际不符。所以定义 $\textit{dfs}(n) = 0$ 会在 $S_{n-1} < 0$ 的情况下算错。

> 注：题目保证 $n\ge 2$。

## 三、递归搜索 + 保存递归返回值 = 记忆化搜索

考虑到整个递归过程中有大量重复递归调用（递归入参相同）。由于递归函数没有副作用，同样的入参无论计算多少次，算出来的结果都是一样的，因此可以用**记忆化搜索**来优化：

- 如果一个状态（递归入参）是第一次遇到，那么可以在返回前，把状态及其结果记到一个 $\textit{memo}$ 数组中。
- 如果一个状态不是第一次遇到（$\textit{memo}$ 中保存的结果不等于 $\textit{memo}$ 的初始值），那么可以直接返回 $\textit{memo}$ 中保存的结果。

⚠**注意**：$\textit{memo}$ 数组的**初始值**一定不能等于要记忆化的值！例如初始值设置为 $0$，并且要记忆化的 $\textit{dfs}(i)$ 也等于 $0$，那就没法判断 $0$ 到底表示第一次遇到这个状态，还是表示之前遇到过了，从而导致记忆化失效。一般把初始值设置为 $-1$。本题 $\textit{dfs}(i)$ 可能是负数，可以把初始值设置为 $\infty$ 或 $-\infty$。

> Python 用户可以无视上面这段，直接用 `@cache` 装饰器。

关于记忆化搜索的原理，请看视频讲解 [动态规划入门：从记忆化搜索到递推【基础算法精讲 17】](https://www.bilibili.com/video/BV1Xj411K7oF/)，其中包含把记忆化搜索 1:1 翻译成递推的技巧。

```py [sol-Python3]
class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        n = len(stones)
        s = list(accumulate(stones))

        @cache  # 缓存装饰器，避免重复计算 dfs（一行代码实现记忆化）
        def dfs(i: int) -> int:
            if i == n - 1:
                return s[-1]
            return max(dfs(i + 1), s[i] - dfs(i + 1))

        return dfs(1)
```

```java [sol-Java]
class Solution {
    public int stoneGameVIII(int[] stones) {
        int n = stones.length;
        int[] sum = new int[n];
        sum[0] = stones[0];
        for (int i = 1; i < n; i++) {
            sum[i] = sum[i - 1] + stones[i];
        }

        int[] memo = new int[n - 1];
        Arrays.fill(memo, Integer.MAX_VALUE); // MAX_VALUE 表示该状态没有计算过
        return dfs(1, sum, memo);
    }

    private int dfs(int i, int[] sum, int[] memo) {
        int n = sum.length;
        if (i == n - 1) {
            return sum[n - 1];
        }
        if (memo[i] != Integer.MAX_VALUE) { // 之前计算过
            return memo[i];
        }
        int res = Math.max(dfs(i + 1, sum, memo), sum[i] - dfs(i + 1, sum, memo));
        return memo[i] = res; // 记忆化
    }
}
```

```cpp [sol-C++]
class Solution {
public:
    int stoneGameVIII(vector<int>& stones) {
        int n = stones.size();
        vector<int> sum(n);
        partial_sum(stones.begin(), stones.end(), sum.begin());
        vector<int> memo(n - 1, INT_MAX); // INT_MAX 表示该状态没有计算过

        auto dfs = [&](this auto&& dfs, int i) -> int {
            if (i == n - 1) {
                return sum[n - 1];
            }

            int& res = memo[i]; // 注意这里是引用
            if (res != INT_MAX) { // 之前计算过
                return res;
            }

            res = max(dfs(i + 1), sum[i] - dfs(i + 1));
            return res;
        };

        return dfs(1);
    }
};
```

```go [sol-Go]
func stoneGameVIII(stones []int) int {
	n := len(stones)
	sum := make([]int, n)
	sum[0] = stones[0]
	for i := 1; i < n; i++ {
		sum[i] = sum[i-1] + stones[i]
	}
	memo := make([]int, n-1)
	for i := range memo {
		memo[i] = math.MaxInt // MaxInt 表示该状态没有计算过
	}

	var dfs func(int) int
	dfs = func(i int) int {
		if i == n-1 {
			return sum[n-1]
		}
		p := &memo[i]
		if *p == math.MaxInt { // 没有计算过
			*p = max(dfs(i+1), sum[i]-dfs(i+1))
		}
		return *p // 记忆化
	}

	return dfs(1)
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{stones}$ 的长度。由于每个状态只会计算一次，记忆化搜索的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题状态个数为 $\mathcal{O}(n)$，单个状态的计算时间为 $\mathcal{O}(1)$，所以总的时间复杂度为 $\mathcal{O}(n)$。
- 空间复杂度：$\mathcal{O}(n)$。

## 四、1:1 翻译成递推

我们可以去掉递归中的「递」，只保留「归」的部分，即自底向上计算。

具体来说，$f[i]$ 的定义和 $\textit{dfs}(i)$ 的定义是完全一样的，都表示在剩余石子为 $S_{i-1},a[i],a[i+1],\ldots,a[n-1]$ 的情况下，先手得分减去后手得分的最大值。

相应的递推式（状态转移方程）也和 $\textit{dfs}$ 一样：

$$
f[i] = \max(f[i+1], S_i - f[i+1])
$$

初始值 $f[n-1]=S_{n-1}$，翻译自递归边界 $\textit{dfs}(n-1) = S_{n-1}$。

答案为 $f[1]$，翻译自递归入口 $\textit{dfs}(1)$。注意不能是 $f[0]$，请仔细看 $f$ 的定义，这会产生负数下标。

```py [sol-Python3]
class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        n = len(stones)
        s = list(accumulate(stones))
        f = [0] * n
        f[-1] = s[-1]
        for i in range(n - 2, 0, -1):
            f[i] = max(f[i + 1], s[i] - f[i + 1])
        return f[1]
```

```java [sol-Java]
class Solution {
    public int stoneGameVIII(int[] stones) {
        int n = stones.length;
        int[] sum = new int[n];
        sum[0] = stones[0];
        for (int i = 1; i < n; i++) {
            sum[i] = sum[i - 1] + stones[i];
        }

        int[] f = new int[n];
        f[n - 1] = sum[n - 1];
        for (int i = n - 2; i > 0; i--) {
            f[i] = Math.max(f[i + 1], sum[i] - f[i + 1]);
        }
        return f[1];
    }
}
```

## 五、空间优化

$f$ 可以优化成一个变量。

对于 $s$，可以先初始化为 $\textit{stones}$ 的总和，然后在倒序遍历的过程中减去 $\textit{stones}[i+1]$，就得到了前缀 $[0,i]$ 的和。

```py [sol-Python3]
class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        f = s = sum(stones)
        for i in range(len(stones) - 2, 0, -1):
            s -= stones[i + 1]
            f = max(f, s - f)  # 改成 if 判断更快，见写法二
        return f
```

```py [sol-Python3 写法二]
class Solution:
    def stoneGameVIII(self, stones: List[int]) -> int:
        f = s = sum(stones)
        for i in range(len(stones) - 2, 0, -1):
            s -= stones[i + 1]
            if s - f > f:
                f = s - f
        return f
```

```java [sol-Java]
class Solution {
    public int stoneGameVIII(int[] stones) {
        int sum = 0;
        for (int x : stones) {
            sum += x;
        }

        int f = sum;
        for (int i = stones.length - 2; i > 0; i--) {
            sum -= stones[i + 1];
            f = Math.max(f, sum - f);
        }
        return f;
    }
}
```

func stoneGameVIII(stones []int) int {
	sum := 0
	for _, x := range stones {
		sum += x
	}

	f := sum
	for i := len(stones) - 2; i > 0; i-- {

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{stones}$ 的长度。
