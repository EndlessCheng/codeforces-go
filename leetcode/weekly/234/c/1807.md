由于题目保证 $s$ 没有嵌套括号对，所以只需找到每对匹配的左右括号，把括号内的子串替换成 $\textit{knowledge}$ 中的对应 $\textit{value}$。

为了快速找到子串在 $\textit{knowledge}$ 中的对应 $\textit{value}$，我们可以先把 $\textit{knowledge}$ 转化成一个哈希表。

为了找到每对匹配的左右括号，我们可以：

- 遇到左括号时，用一个变量 $\textit{left}$ 记录该左括号的下标。
- 遇到右括号 $s[i]$ 时，子串 $[\textit{left}+1,i-1]$ 即为要替换的子串。替换后，把 $\textit{left}$ 置为 $-1$，这样我们可以判断一个字母是否在括号中。
- 如果不是左右括号且 $\textit{left} < 0$，那么当前字母不在括号中，直接添加到答案末尾。

```py [sol-Python3]
class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        # 每个 knowledge[i] 都是一个键值对，插入字典
        # 查字典时，如果 key 不在字典中，那么 value 为 '?'
        d = defaultdict(lambda: '?', knowledge)

        ans = []
        left = -1
        for i, ch in enumerate(s):
            if ch == '(':
                left = i  # 记录左括号的位置
            elif ch == ')':
                # 替换左右括号之间的子串
                t = s[left + 1: i]
                ans.append(d[t])
                left = -1
            elif left < 0:  # ch 不在左右括号之间
                ans.append(ch)
        return ''.join(ans)
```

class Solution {
    public String evaluate(String s, List<List<String>> knowledge) {
        HashMap<String, String> mp = HashMap.newHashMap(knowledge.size()); // 预分配空间
        for (List<String> kv : knowledge) {
            mp.put(kv.get(0), kv.get(1));
        }

        StringBuilder ans = new StringBuilder();
        int n = s.length();
        int left = -1;
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                left = i; // 记录左括号的位置
            } else if (ch == ')') {
                // 替换左右括号之间的子串
                String t = s.substring(left + 1, i);
                t = mp.getOrDefault(t, "?");
                ans.append(t);
                left = -1;
            } else if (left < 0) { // ch 不在左右括号之间
                ans.append(ch);
            }
        }
        return ans.toString();
    }
}

                left = -1;
            } else if (left < 0) { // ch 不在左右括号之间

            }
        }

			left = -1
		} else if left < 0 { // ch 不在左右括号之间

		}
	}
	return string(ans)

```rust [sol-Rust]
use std::collections::HashMap;

impl Solution {
    pub fn evaluate(s: String, knowledge: Vec<Vec<String>>) -> String {
        let mp = knowledge
            .iter()
            .map(|kv| (kv[0].as_str(), kv[1].as_str()))
            .collect::<HashMap<_, _>>();

        let mut ans = vec![];
        let mut left = usize::MAX;
        for (i, ch) in s.bytes().enumerate() {
            if ch == b'(' {
                left = i; // 记录左括号的位置
            } else if ch == b')' {
                // 替换左右括号之间的子串
                if let Some(value) = mp.get(&s[left + 1..i]) {
                    ans.extend_from_slice(value.as_bytes());
                } else {
                    ans.push(b'?');
                }
                left = usize::MAX;
            } else if left == usize::MAX { // ch 不在左右括号之间
                ans.push(ch);
            }
        }
        unsafe { String::from_utf8_unchecked(ans) }
    }
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}((m+n)L)$，其中 $n$ 是 $s$ 的长度，$m$ 是 $\textit{knowledge}$ 的长度，$L\le 10$ 是单个字符串的最大长度。构建哈希表时，每个插入的 $\textit{key}$ 都需要计算哈希值，这会消耗 $\mathcal{O}(mL)$ 时间。替换时，最坏有 $\mathcal{O}(n)$ 个字母都被替换成了长为 $L$ 的字符串，这需要 $\mathcal{O}(nL)$ 的时间。
- 空间复杂度：$\mathcal{O}(m + nL)$。
