根据题意：

- $\texttt{()}$ 是 $1$ 分。$\texttt{()}$ 的深度为 $0$。
- $\texttt{(())}$ 是 $2$ 分。最内层的 $\texttt{()}$ 的深度为 $1$。
- $\texttt{((()))}$ 是 $4$ 分。最内层的 $\texttt{()}$ 的深度为 $2$。
- $\texttt{(((())))}$ 是 $8$ 分。最内层的 $\texttt{()}$ 的深度为 $3$。
- 依此类推。

我们可以直接计算 $\texttt{()}$ 对答案的**最终贡献**。设 $\texttt{()}$ 的深度为 $d$（外面套了多少层括号），那么 $\texttt{()}$ 对答案的最终贡献为

$$
2^d
$$

累加所有 $\texttt{()}$ 对答案的最终贡献，即为答案。

```py [sol-Python3]
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        ans = depth = 0
        for i, ch in enumerate(s):
            if ch == '(':
                depth += 1
            else:
                depth -= 1
                if s[i - 1] == '(':  # 发现一对 "()"
                    ans += 1 << depth
        return ans
```
