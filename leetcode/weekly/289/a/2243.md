```py [sol-Python3]
class Solution:
    def digitSum(self, s: str, k: int) -> str:
        while len(s) > k:
            t = []
            for i in range(0, len(s), k):  # k 个一组
                total = sum(map(int, s[i: i + k]))  # 计算数字和
                t.append(str(total))
            s = ''.join(t)
        return s
```

#### 复杂度分析

设 $n$ 是 $s$ 的长度且 $n > k$（$n\le k$ 的情况不会执行操作）。我们把 $s$ 分成了 $\left\lceil\dfrac{n}{k}\right\rceil < \dfrac{n}{k}+1 < \dfrac{2n}{k}$ 组，每组的数字之和 $\le 9k$，十进制长度 $\le 1 + \left\lfloor \log_{10} (9k) \right\rfloor \le 1 + \log_{10} (9k)$。所以一轮操作后，新字符串的长度 $< \dfrac{2n(1 + \log_{10} (9k))}{k}$。由于 $f(k) = \dfrac{1 + \log_{10} (9k)}{k}$ 在 $k\ge 2$ 时是减函数，所以最坏情况是 $k=2$。

下面讨论 $k=2$ 的情况。

当 $k=2$ 时，设有 $m = \left\lfloor\dfrac{n}{2}\right\rfloor$ 个长为 $2$ 的组，每一组的数字之和都在 $[0,18]$ 中。按照数字之和是个位数还是两位数，把所有组分为如下两类：

- 组 $A$：数字之和在 $[0,9]$ 中。每有一个这样的组，新字符串的长度就会减少 $1$。
- 组 $B$：数字之和在 $[10,18]$ 中。虽然组的长度没变，但如果这些和相邻，例如 $18181818$，那么再操作一轮，无论是 $1+8$ 还是 $8+1$，新字符串都会缩短。

> **注**：此外还有组 $C$。如果 $n$ 是奇数，那么最后一个数字单独组成一组。该组不影响新字符串的长度，不讨论。

设有 $x$ 个组 $A$，$m-x$ 个组 $B$。分类讨论：

- 如果 $x\ge \left\lfloor\dfrac{n}{3}\right\rfloor$，那么新字符串的长度为 $n-x \le n - \left\lfloor\dfrac{n}{3}\right\rfloor < n - \left(\dfrac{n}{3}-1\right) = \dfrac{2n}{3} + 1$。
- 如果 $x < \left\lfloor\dfrac{n}{3}\right\rfloor$，即 $x\le \left\lfloor\dfrac{n}{3}\right\rfloor-1$，再操作一轮后，由于每个组 $A$ 都只能与一个数字结合，所以组 $A$ 要想「阻止」组 $B$ 的长度减少，构造方案为 $ABAABA\cdots$，两个组 $A$ 对应一个组 $B$，例如 $91899189\cdots$。如果 $x$ 是奇数，可以额外阻止一个组 $B$ 的长度减少。所以可以阻止 $\left\lceil\dfrac{x}{2}\right\rceil = \left\lfloor\dfrac{x+1}{2}\right\rfloor \le \left\lfloor\dfrac{n}{6}\right\rfloor$ 个组 $B$ 的长度减少。所以至少有 $(m-x) - \left\lfloor\dfrac{n}{6}\right\rfloor$ 个组 $B$ 的长度要减少。结合第一轮长度减少了 $x$，所以两轮操作后，长度至少减少 $m-\left\lfloor\dfrac{n}{6}\right\rfloor > \left(\dfrac{n}{2} - 1\right) - \dfrac{n}{6} = \dfrac{n}{3} - 1$。所以新字符串的长度 $< n-\left(\dfrac{n}{3} - 1\right) = \dfrac{2n}{3} + 1$。**注**：关于下取整式子的化简，证明见 [下取整恒等式及其应用](https://zhuanlan.zhihu.com/p/1893240318645732760)。

综上所述，两轮操作后，新字符串的长度 $< \dfrac{2n}{3} + 1$。

如果 $n\ge 12$，那么 $\dfrac{2n}{3} + 1\le \dfrac{3n}{4}$。如果 $n < 12$，那么常数轮后停止操作。

所有轮数的字符串长度之和不超过

$$
2\cdot\left[n + \dfrac{3}{4}n + \left(\dfrac{3}{4}\right)^2 n + \cdots\right] + C < 8n + C = \mathcal{O}(n)
$$

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
- 空间复杂度：$\mathcal{O}(n)$。
