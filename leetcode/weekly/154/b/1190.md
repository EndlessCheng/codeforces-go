## 方法一：递归

做法类似 [394. 字符串解码](https://leetcode.cn/problems/decode-string/)，[我的题解](https://leetcode.cn/problems/decode-string/solutions/3744428/di-gui-yong-zhan-mo-ni-di-gui-pythonjava-kcsv/)。

在递归过程中，用一个在递归函数外的变量 $i$ 表示当前下标，每遍历到一个字符，就把 $i$ 加一。

- 遇到字母：把字母加到返回值 $\textit{res}$ 的末尾。
- 遇到左括号：递归，初始化 $\textit{res}$ 为空串。递归返回后，把递归返回结果加到 $\textit{res}$ 的末尾。
- 遇到右括号：反转 $\textit{res}$，然后返回 $\textit{res}$。

```py [sol-Python3]
class Solution:
    def reverseParentheses(self, s: str) -> str:
        i = 0

        def f() -> List[str]:
            nonlocal i
            res = []
            while i < len(s):
                ch = s[i]
                i += 1
                if ch == ')':  # 归
                    res.reverse()
                    return res
                if ch == '(':  # 递
                    res += f()
                else:  # 字母
                    res.append(ch)
            return res

        return ''.join(f())
```

```java [sol-Java]
class Solution {
    private int i = 0;

    public String reverseParentheses(String S) {
        char[] s = S.toCharArray();
        return f(s).toString();
    }

    private StringBuilder f(char[] s) {
        StringBuilder res = new StringBuilder();
        while (i < s.length) {
            char ch = s[i];
            i++;
            if (ch == ')') { // 归
                return res.reverse();
            }
            if (ch == '(') { // 递
                res.append(f(s));
            } else { // 字母
                res.append(ch);
            }
        }
        return res;
    }
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 是 $s$ 的长度。递归 $\mathcal{O}(n)$ 次，每次处理长为 $\mathcal{O}(n)$ 的字符串。例如 $s = \texttt{((((abcd))))}$ 的情况，会把中间长为 $\mathcal{O}(n)$ 的字符串反转 $\mathcal{O}(n)$ 次。
- 空间复杂度：$\mathcal{O}(n)$。

## 方法二：左右横跳

当我们遇到左括号时，直接跳到右括号的左侧，倒着遍历，就不需要反转了。倒着遍历，再次遇到左括号时，跳到右括号的右侧，继续向右遍历。对于遇到右括号的情况，同理，跳到左括号的相应位置。

如何实现这个逻辑？

具体地，初始化步长 $\textit{step}=1$。如果 $s[i]$ 是括号，那么跳到对应的括号位置，然后把步长取反，即 $\textit{step}$ 更新为 $-\textit{step}$。每次循环末尾把 $i$ 更新为 $i + \textit{step}$。

当我们再次遇到左括号时，$\textit{step}$ 负负得正，我们会跳到右括号的右侧，继续向右遍历。

举个例子。$s = \texttt{a(bcd)e}$ 的访问顺序如下，其中 $s[1] = \texttt{(}$ 访问了两次。

$$
\begin{array}{r|}
字符 & \texttt{a} & \texttt{(} & \texttt{b} & \texttt{c} & \texttt{d} & \texttt{)} & \texttt{e} \\
访问顺序 & 1 & 2,6 & 5 & 4 & 3 & - & 7
\end{array}
$$

对于多层嵌套的情况，如示例 2 的 $s = \texttt{(u(love)i)}$，访问顺序如下。

$$
\begin{array}{r|}
字符 & \texttt{(} & \texttt{u} & \texttt{(} & \texttt{l} & \texttt{o} & \texttt{v} & \texttt{e} & \texttt{)} & \texttt{i} & \texttt{)} \\
访问顺序 & 1,10 & 9 & - & 4 & 5 & 6 & 7 & 3,8 & 2 & -  
\end{array}
$$

最后，如何快出求出每个括号要跳到哪个位置？

预处理。从左到右遍历 $s$。遍历到左括号 $s[i]$ 时，把下标 $i$ 入栈。遍历到右括号 $s[i]$ 时，弹出栈顶的下标 $j$，然后在下标 $i$ 和 $j$ 之间建立双向链接 $\textit{links}[i] = j,\ \textit{links}[j] = i$。

```py [sol-Python3]
class Solution:
    def reverseParentheses(self, s: str) -> str:
        n = len(s)
        links = [0] * n
        st = []
        for i, ch in enumerate(s):
            if ch == '(':
                st.append(i)
            elif ch == ')':
                # 右括号与栈顶左括号配对，下标建立双向链接
                j = st.pop()
                links[i] = j
                links[j] = i

        ans = []
        step = 1
        i = 0
        while i < n:
            ch = s[i]
            if ch == '(' or ch == ')':
                i = links[i]  # 跳到对应的括号位置
                step = -step  # 反向移动
            else:
                ans.append(ch)
            i += step
        return ''.join(ans)
```

```java [sol-Java]
class Solution {
    public String reverseParentheses(String S) {
        char[] s = S.toCharArray();
        int n = s.length;
        int[] links = new int[n];
        int[] st = new int[n]; // 用数组模拟栈，比 ArrayDeque 更快
        int top = -1; // 栈顶下标

        for (int i = 0; i < n; i++) {
            char ch = s[i];
            if (ch == '(') {
                st[++top] = i; // 入栈
            } else if (ch == ')') {
                // 右括号与栈顶左括号配对，下标建立双向链接
                int j = st[top--]; // 出栈
                links[i] = j;
                links[j] = i;
            }
        }

        StringBuilder ans = new StringBuilder();
        int step = 1;
        for (int i = 0; i < n; i += step) {
            char ch = s[i];
            if (ch == '(' || ch == ')') {
                i = links[i]; // 跳到对应的括号位置
                step = -step; // 反向移动
            } else {
                ans.append(ch);
            }
        }
        return ans.toString();
    }
}
```

```cpp [sol-C++]
class Solution {
public:
    string reverseParentheses(string s) {
        int n = s.size();
        vector<int> links(n);
        stack<int> st;
        for (int i = 0; i < n; i++) {
            char ch = s[i];
            if (ch == '(') {
                st.push(i);
            } else if (ch == ')') {
                // 右括号与栈顶左括号配对，下标建立双向链接
                int j = st.top();
                st.pop();
                links[i] = j;
                links[j] = i;
            }
        }

        string ans;
        int step = 1;
        for (int i = 0; i < n; i += step) {
            char ch = s[i];
            if (ch == '(' || ch == ')') {
                i = links[i]; // 跳到对应的括号位置
                step = -step; // 反向移动
            } else {
                ans += ch;
            }
        }
        return ans;
    }
};
```

```go [sol-Go]
func reverseParentheses(s string) string {
	n := len(s)
	links := make([]int, n)
	st := []int{}
	for i, ch := range s {
		if ch == '(' {
			st = append(st, i)
		} else if ch == ')' {
			// 右括号与栈顶左括号配对，下标建立双向链接
			j := st[len(st)-1]
			st = st[:len(st)-1]
			links[i] = j
			links[j] = i
		}
	}

	ans := []byte{}
	step := 1
	for i := 0; i < n; i += step {
		ch := s[i]
		if ch == '(' || ch == ')' {
			i = links[i] // 跳到对应的括号位置
			step = -step // 反向移动
		} else {
			ans = append(ans, ch)
		}
	}
	return string(ans)
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。每对括号会执行「左跳右」两次或者「右跳左」两次，每个字母会被遍历一次。
- 空间复杂度：$\mathcal{O}(n)$。
