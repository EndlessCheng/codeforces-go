设 $\textit{nums}$ 中的小于 $\textit{target}$ 的元素个数为 $\textit{less}$，等于 $\textit{target}$ 的元素个数为 $\textit{equal}$。

排序后，相同的数是**连续**的。等于 $\textit{target}$ 的第一个数的下标为 $\textit{less}$，最后一个数的下标为 $\textit{less}+\textit{equal}-1$。

```py [sol-Python3]
class Solution:
    def targetIndices(self, nums: List[int], target: int) -> List[int]:
        less = equal = 0
        for x in nums:
            if x < target:
                less += 1
            elif x == target:
                equal += 1

        return list(range(less, less + equal))
```

```java [sol-Java]
class Solution {
    public List<Integer> targetIndices(int[] nums, int target) {
        int less = 0;
        int equal = 0;
        for (int x : nums) {
            if (x < target) {
                less++;
            } else if (x == target) {
                equal++;
            }
        }

        List<Integer> ans = new ArrayList<>(equal);
        for (int i = 0; i < equal; i++) {
            ans.add(less + i);
        }
        return ans;
    }
}
```

```rust [sol-Rust]
impl Solution {
    pub fn target_indices(nums: Vec<i32>, target: i32) -> Vec<i32> {
        let mut less = 0;
        let mut equal = 0;
        for x in nums {
            if x < target {
                less += 1;
            } else if x == target {
                equal += 1;
            }
        }

        (less..less + equal).collect()
    }
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
- 空间复杂度：$\mathcal{O}(1)$。返回值不计入。
