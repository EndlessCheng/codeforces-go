把所有偶数下标元素 $\textit{nums}[0],\textit{nums}[2],\textit{nums}[4],\cdots$ 记作集合 $A$，所有奇数下标元素 $\textit{nums}[1],\textit{nums}[3],\textit{nums}[5],\cdots$ 记作集合 $B$。注意这两个集合是**没有交集**的。

目标是让 $A$ 中都是偶数，$B$ 中都是奇数。

可以把 $A$ 中的奇数和 $B$ 中的偶数交换。

首先，找到 $A$ 中**最左边**的奇数 $\textit{nums}[i]$ 和 $B$ 中**最左边**的偶数 $\textit{nums}[j]$，交换这两个数。

> 注：由于偶数下标和奇数下标互相独立，从左边开始找还是从右边开始找，都可以。

交换后，下标在 $0,2,4,\ldots,i$ 中的数都是偶数，下标在 $1,3,5,\ldots,j$ 中的数都是奇数。于是问题变成下标 $i+2,i+4,\cdots$ 与下标 $j+2,j+4,\cdots$ 中的数如何交换，这是个规模更小的子问题，处理方式同上。

重复该过程，直到 $i\ge n$ 为止，此时没有元素需要交换，算法结束。

> 注：题目保证数组中恰有一半是偶数，恰有一半是奇数。

```py [sol-Python3]
class Solution:
    def sortArrayByParityII(self, nums: List[int]) -> List[int]:
        i, j = 0, 1
        while i < len(nums):
            if nums[i] % 2 == 0:  # 寻找偶数下标中最左边的奇数
                i += 2
            elif nums[j] % 2 == 1:  # 寻找奇数下标中最左边的偶数
                j += 2
            else:
                nums[i], nums[j] = nums[j], nums[i]
                i += 2
                j += 2
        return nums
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{nums}$ 的长度。
- 空间复杂度：$\mathcal{O}(1)$。
