对于一个合法括号字符串，其每个右括号都要在左边有对应的左括号。

我们可以在遍历 $s$ 的过程中，维护尚未配对的左括号的个数 $\textit{left}$：

- 如果 $s[i]$ 是左括号，把 $\textit{left}$ 增加一。
- 如果 $s[i]$ 是右括号：
    - 如果 $\textit{left} > 0$，那么左右括号配对，把 $\textit{left}$ 减少一。
    - 如果 $\textit{left} = 0$，那么必须补一个左括号（可以插在 $s[i]$ 左侧任意位置，例如 $s$ 开头）。

遍历结束后，如果 $\textit{left} > 0$（有未配对的左括号），那么补上 $\textit{left}$ 个右括号（可以插在 $s$ 末尾）。

```py [sol-Python3]
class Solution:
    def minAddToMakeValid(self, s: str) -> int:
        left = 0  # 未配对的左括号的个数
        ans = 0
        for ch in s:
            if ch == '(':
                left += 1
            elif left > 0:
                left -= 1  # 左右括号配对
            else:  # 右括号太多了
                ans += 1  # 在 ch 左边任意位置插入一个左括号，与 ch 配对

        # 循环结束后，如果 left > 0，说明有 left 个多余的左括号
        # 在 s 末尾插入 left 个右括号
        return ans + left
```
