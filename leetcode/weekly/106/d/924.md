> 仔细读题：我们移除的仅仅是 $\textit{initial}$ 列表中的节点，不是图中的节点，不会影响图的结构。

一个大小为 $k$ 的连通块内，如果只有一个节点 $x$ 被感染（$x$ 在 $\textit{initial}$ 中），那么从 $\textit{initial}$ 中移除 $x$ 后，这个连通块不会被感染，从而让 $M(\textit{initial})$ 减少 $k$。

而如果连通块内至少有两个节点被感染，无论移除哪个节点，仍然会导致连通块的所有节点被感染，$M(\textit{initial})$ 不变。

所以我们要找的是**只包含一个被感染节点的连通块**，并且这个连通块**越大越好**。

算法如下：

1. 遍历 $\textit{initial}$ 中的节点 $x$。
2. 如果 $x$ 没有被访问过，那么从 $x$ 开始 DFS，同时用一个 $\textit{vis}$ 数组标记访问过的节点。
3. DFS 过程中，统计连通块的大小 $\textit{size}$。
4. DFS 过程中，记录访问到的在 $\textit{initial}$ 中的节点。
5. DFS 结束后，如果发现该连通块只有一个在 $\textit{initial}$ 中的节点，并且该连通块的大小比最大的连通块更大，那么更新最大连通块的大小，以及答案节点 $x$。如果一样大，就更新答案节点的最小值。
6. 最后，如果没找到符合要求的节点，返回 $\min(\textit{initial})$；否则返回答案节点。

如何判断出「连通块内有一个或多个在 $\textit{initial}$ 中的节点」？要记录被感染的节点列表吗？

其实无需记录节点列表，而是用如下状态机：

![LC924.png](https://pic.leetcode.cn/1712906008-eKMFbE-LC924.png)

- 初始状态为 $-1$。
- 如果状态是 $-1$，在找到被感染的节点 $x$ 后，状态变为 $x$。
- 如果状态是非负数 $x$，在找到另一个被感染的节点后，状态变为 $-2$。如果状态已经是 $-2$，则不变。

此外，可以用一个哈希表或者布尔数组，记录哪些点在 $\textit{initial}$ 中，从而在 DFS 中快速判断当前节点是否在 $\textit{initial}$ 中。

```py [sol-Python3]
class Solution:
    def minMalwareSpread(self, graph: List[List[int]], initial: List[int]) -> int:
        st = set(initial)
        vis = [False] * len(graph)
        def dfs(x: int) -> None:
            vis[x] = True
            nonlocal node_id, size
            size += 1
            # 按照状态机更新 node_id
            if node_id != -2 and x in st:
                node_id = x if node_id == -1 else -2
            for y, conn in enumerate(graph[x]):
                if conn and not vis[y]:
                    dfs(y)

        ans = -1
        max_size = 0
        for x in initial:
            if vis[x]:
                continue
            node_id = -1
            size = 0
            dfs(x)
            if node_id >= 0 and (size > max_size or size == max_size and node_id < ans):
                ans = node_id
                max_size = size
        return min(initial) if ans < 0 else ans
```

```java [sol-Java]
class Solution {
    private int nodeId, size;

    public int minMalwareSpread(int[][] graph, int[] initial) {
        int n = graph.length;
        boolean[] vis = new boolean[n];
        boolean[] isInitial = new boolean[n];
        int mn = Integer.MAX_VALUE;
        for (int x : initial) {
            isInitial[x] = true;
            mn = Math.min(mn, x);
        }

        int ans = -1;
        int maxSize = 0;
        for (int x : initial) {
            if (vis[x]) {
                continue;
            }
            nodeId = -1;
            size = 0;
            dfs(x, graph, vis, isInitial);
            if (nodeId >= 0 && (size > maxSize || size == maxSize && nodeId < ans)) {
                ans = nodeId;
                maxSize = size;
            }
        }
        return ans < 0 ? mn : ans;
    }

    private void dfs(int x, int[][] graph, boolean[] vis, boolean[] isInitial) {
        vis[x] = true;
        size++;
        // 按照状态机更新 nodeId
        if (nodeId != -2 && isInitial[x]) {
            nodeId = nodeId == -1 ? x : -2;
        }
        for (int y = 0; y < graph[x].length; y++) {
            if (graph[x][y] == 1 && !vis[y]) {
                dfs(y, graph, vis, isInitial);
            }
        }
    }
}
```

```rust [sol-Rust]
impl Solution {
    pub fn min_malware_spread(graph: Vec<Vec<i32>>, initial: Vec<i32>) -> i32 {
        let n = graph.len();
        let mut vis = vec![false; n];
        let mut is_initial = vec![false; n];
        for &x in &initial {
            is_initial[x as usize] = true;
        }

        let mut ans = -1;
        let mut max_size = 0;
        for &x in &initial {
            if vis[x as usize] {
                continue;
            }
            let mut node_id = -1;
            let mut size = 0;
            Self::dfs(x as usize, &graph, &mut vis, &is_initial, &mut node_id, &mut size);
            if node_id >= 0 && (size > max_size || size == max_size && node_id < ans) {
                ans = node_id;
                max_size = size;
            }
        }
        if ans < 0 { *initial.iter().min().unwrap() } else { ans }
    }

    fn dfs(x: usize, graph: &Vec<Vec<i32>>, vis: &mut Vec<bool>, is_initial: &Vec<bool>, node_id: &mut i32, size: &mut i32) {
        vis[x] = true;
        *size += 1;
        // 按照状态机更新 node_id
        if *node_id != -2 && is_initial[x] {
            *node_id = if *node_id == -1 { x as i32 } else { -2 };
        }
        for (y, &conn) in graph[x].iter().enumerate() {
            if conn == 1 && !vis[y] {
                Self::dfs(y, graph, vis, is_initial, node_id, size);
            }
        }
    }
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 为 $\textit{graph}$ 的长度。瓶颈在遍历 $\textit{graph}$ 上。
- 空间复杂度：$\mathcal{O}(n)$。
