把示例 1 的 `(1+(2*3)+((8)/4))+1` 中的 `()` 看成代码中的 `{}`，格式化一下就能看得更清楚：

```text
(
    1 +
    (
        2 * 3
    )
    +
    (
        (
            8
        )
        / 4
    )
)
+ 1
```

由此可见，遇到左括号，嵌套深度（嵌套层数）就增加一，遇到右括号，嵌套深度就减少一。

这也等于当前字符左侧未闭合的左括号的个数。

```py [sol-Python3]
class Solution:
    def maxDepth(self, s: str) -> int:
        ans = depth = 0
        for ch in s:
            if ch == '(':
                depth += 1
                ans = max(ans, depth)
            elif ch == ')':
                depth -= 1
        return ans
```

```java [sol-Java]
class Solution {
    public int maxDepth(String s) {
        int depth = 0;

            }
        }

    }
}
```

```rust [sol-Rust]
impl Solution {
    pub fn max_depth(s: String) -> i32 {
        let mut depth = 0;
        let mut ans = 0;
        for ch in s.bytes() {
            if ch == b'(' {
                depth += 1;
                ans = ans.max(depth);
            } else if ch == b')' {
                depth -= 1;
            }
        }
        ans
    }
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $s$ 的长度。
- 空间复杂度：$\mathcal{O}(1)$。
