设 $T$ 是整个 $\textit{nums}$ 的元素和。设 $S_i$ 是前缀 $[0,i]$ 的元素和，那么后缀 $[i+1,n-1]$ 的元素和为 $T - S_i$。

我们要找的是使下式最小的下标 $i$：

$$
\left| \left\lfloor\dfrac{S_i}{i+1}\right\rfloor - \left\lfloor\dfrac{T - S_i}{n-1-i}\right\rfloor \right|
$$

如果有多个下标 $i$ 都能使上式最小，取其中下标小的。从左到右遍历数组即可。

特殊处理 $i=n-1$ 的情况，此时 $n-1-i = 0$，但分母不能为 $0$。此时绝对差为 $\left\lfloor\dfrac{T}{n}\right\rfloor$。

```py [sol-Python3]
class Solution:
    def minimumAverageDifference(self, nums: list[int]) -> int:
        n = len(nums)
        total = sum(nums)

        min_diff = inf
        ans = s = 0
        for i in range(n - 1):
            s += nums[i]
            diff = abs(s // (i + 1) - (total - s) // (n - 1 - i))
            if diff < min_diff:
                min_diff = diff
                ans = i

        # 特殊处理 i = n-1 的情况
        diff = total // n
        if diff < min_diff:
            ans = n - 1

        return ans
```
