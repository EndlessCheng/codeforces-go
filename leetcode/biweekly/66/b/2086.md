## 方法一：寻找子串

每只仓鼠都需要一个食物桶，所以答案至多为 $\texttt{H}$ 的个数。由于 $\texttt{H.H}$ 只需要一个食物桶，那么用 $\texttt{H}$ 的个数减去 $\texttt{H.H}$ 的个数，即为答案。

如果有 $\texttt{HHH}$，那么中间的仓鼠吃不到食物，返回 $-1$。为方便判断最左或者最右有两只仓鼠的情况，以及 $\textit{hamsters} = \texttt{H}$ 的情况，可以在 $\textit{hamsters}$ 左右两侧各加一个 $\texttt{H}$，从而简化代码逻辑。

```py [sol-Python3]
class Solution:
    def minimumBuckets(self, hamsters: str) -> int:
        if "HHH" in "H" + hamsters + "H":
            return -1
        return hamsters.count("H") - hamsters.count("H.H")
```

```java [sol-Java]
class Solution {
    public int minimumBuckets(String hamsters) {
        if (("H" + hamsters + "H").contains("HHH")) {
            return -1;
        }
        return hamsters.replace(".", "").length() // 'H' 的个数
                - (hamsters.split("H\\.H", -1).length - 1); // "H.H" 的个数
    }
}
```

```cpp [sol-C++]

public:
    int minimumBuckets(string hamsters) {
        if (("H" + hamsters + "H").contains("HHH")) {
            return -1;

        for (size_t i = 0; (i = hamsters.find("H.H", i)) != string::npos; i += 3) {
            cnt++;
        }
        return ranges::count(hamsters, 'H') - cnt;
    }
};
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{hamsters}$ 的长度。
- 空间复杂度：$\mathcal{O}(n)$。

## 方法二：从左到右贪心

如果仓鼠左右两侧都有空位置，那么**优先在右侧放食物桶**，这样如果是 $\texttt{H.H}$，就可以节省一个食物桶。

```py [sol-Python3]
class Solution:
    def minimumBuckets(self, hamsters: str) -> int:
        last_food = -2  # 上一个食物桶的位置
        ans = 0
        for i, ch in enumerate(hamsters):
            if ch == '.':
                continue
            # 仓鼠
            if last_food == i - 1:  # 左侧有食物桶，嚼嚼嚼
                continue
            if i < len(hamsters) - 1 and hamsters[i + 1] == '.':  # 先考虑在右侧放食物桶
                last_food = i + 1
                ans += 1
            elif i > 0 and hamsters[i - 1] == '.':  # 再考虑在左侧放食物桶
                ans += 1  # 无需记录 last_food（太远了）
            else:  # 饿死了 X_X
                return -1
        return ans
```
