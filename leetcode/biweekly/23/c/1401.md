**核心想法**：

1. 找到在矩形中的到圆心 $(x_\textit{center},y_\textit{center})$ 最近的点 $(x, y)$。
2. 判断点 $(x, y)$ 是否在圆中。

由于点 $(x,y)$ 在矩形中，所以有 $x_1\le x\le x_2$ 且 $y_1\le y\le y_2$。

根据勾股定理，点 $(x, y)$ 到圆心 $(x_\textit{center},y_\textit{center})$ 的距离的平方为

$$
d^2 = (x - x_\textit{center})^2 + (y - y_\textit{center})^2
$$

为了最小化上式，问题变成：

- 在闭区间 $[x_1,x_2]$ 中找一个离 $x_\textit{center}$ 最近的数 $x$。
- 在闭区间 $[y_1,y_2]$ 中找一个离 $y_\textit{center}$ 最近的数 $y$。

对于 $x$：

- 如果 $x_\textit{center}$ 在闭区间 $[x_1,x_2]$ 内，那么 $x = x_\textit{center}$。
- 如果 $x_\textit{center}$ 在闭区间 $[x_1,x_2]$ 左侧，那么 $x = x_1$。
- 如果 $x_\textit{center}$ 在闭区间 $[x_1,x_2]$ 右侧，那么 $x = x_2$。

换句话说，我们要把 $x_\textit{center}$ 修正到闭区间 $[x_1,x_2]$ 内，小了就和 $x_1$ 取最大值，大了就和 $x_2$ 取最小值。所以这三种情况可以用一个式子表达：

$$
x = \max(x_1, \min(x_\textit{center}, x_2))
$$

对于 $y$，同理有

$$
y = \max(y_1, \min(y_\textit{center}, y_2))
$$

求出点 $(x,y)$ 后，如果

$$
(x - x_\textit{center})^2 + (y - y_\textit{center})^2 \le \textit{radius}^2
$$

成立，那么点 $(x,y)$ 在圆中，说明圆和矩形相交。否则，到圆心最近的点都不在圆中，说明圆和矩形不相交。

```py [sol-Python3]
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int, x1: int, y1: int, x2: int, y2: int) -> bool:
        # 找到在矩形中的到圆心 (xCenter, yCenter) 最近的点 (x, y)
        x = max(x1, min(xCenter, x2))
        y = max(y1, min(yCenter, y2))

        # 判断 (x, y) 是否在圆中
        return (x - xCenter) ** 2 + (y - yCenter) ** 2 <= radius ** 2
```

impl Solution {
    pub fn check_overlap(radius: i32, x_center: i32, y_center: i32, x1: i32, y1: i32, x2: i32, y2: i32) -> bool {
        // 找到在矩形中的到圆心 (x_center, y_center) 最近的点 (x, y)
        let x = x_center.clamp(x1, x2); // x_center.max(x1).min(x2)
