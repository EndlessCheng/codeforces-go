讨论一行能容纳几个四人小组：

- 如果这一行的座位 $2$ 到 $9$ 都是空的（没被预定），那么这一行可以容纳 $2$ 个四人小组。
- 否则，如果座位 $2$ 到 $5$ 都是空的，或者座位 $4$ 到 $7$ 都是空的，或者座位 $6$ 到 $9$ 都是空的，那么这一行可以容纳 $1$ 个四人小组。
- 否则，这一行无法容纳四人小组。

用哈希表处理 $\textit{reservedSeats}$：

- 哈希表的 key 是行编号 $\textit{row}$。
- 哈希表的 value 记录这一行有哪些座位被预定。由于我们只关心座位 $2$ 到 $9$，所以忽略编号小于 $2$ 或者编号大于 $9$ 的座位。

对于 value，可以用布尔数组记录哪些座位被预定，也可以用一个二进制数记录哪些座位被预定。

二进制数从低到高第 $i$ 位（$i$ 从 $0$ 开始）表示座位编号 $i+2$ 被预定。

例如二进制数 $10001011$ 表示座位编号 $2,3,5,9$ 被预定。

利用位运算，可以快速判断二进制数 $x$ 中是否有连续 $4$ 个 $0$：

- 判断 `(x & 0b1111) == 0`，只有 $x$ 的低 $4$ 位全是 $0$，AND 结果才是 $0$。如果为真，则座位 $2$ 到 $5$ 都是空的。
- 判断 `(x & 0b111100) == 0`。如果为真，则座位 $4$ 到 $7$ 都是空的。
- 判断 `(x & 0b11110000) == 0`。如果为真，则座位 $6$ 到 $9$ 都是空的。

```py [sol-Python3]
class Solution:
    def maxNumberOfFamilies(self, n: int, reservedSeats: List[List[int]]) -> int:
        seats = defaultdict(int)  # 2~9 有预定座位的行 -> 这一行具体哪些座位被预定
        for row, seat in reservedSeats:
            if 2 <= seat <= 9:
                seats[row] |= 1 << (seat - 2)  # 把二进制数的 seat-2 这一位变成 1

        # 注意：如果某一行只有 1 和 10 被预定，那么这一行不会插到哈希表中（相当于这一行是空的）
        # 示例 1 只有第 1 行和第 2 行插到哈希表中
        empty_rows = n - len(seats)
        ans = empty_rows * 2  # 一个空行可以容量 2 个四人小组
        for x in seats.values():
            # 在哈希表中的行，由于 2~9 至少一个座位被预定，所以至多容纳 1 个四人小组，ans 至多增加 1
            if x & 0b1111 == 0 or x & 0b111100 == 0 or x & 0b11110000 == 0:
                ans += 1
        return ans
```

class Solution {
    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        Map<Integer, Integer> seats = new HashMap<>(); // 2~9 有预定座位的行 -> 这一行具体哪些座位被预定
        for (int[] r : reservedSeats) {
            int seat = r[1];
            if (2 <= seat && seat <= 9) {
                seats.merge(r[0], 1 << (seat - 2), (a, b) -> a | b); // 把二进制数的 seat-2 这一位变成 1
            }
        }

            }
        }
