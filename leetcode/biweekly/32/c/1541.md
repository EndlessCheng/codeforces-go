对于这类合法括号字符串的问题，通用套路是在遍历 $s$ 的过程中，用一个变量 $\textit{left}$ 维护当前**尚未配对**的左括号的个数。

- 如果 $s[i]$ 是左括号，把 $\textit{left}$ 增加一。
- 如果 $s[i]$ 是右括号：
    - 左右括号配对。如果 $\textit{left} > 0$，把 $\textit{left}$ 减少一；如果 $\textit{left} = 0$，必须补一个左括号（可以插在 $s$ 开头）。
    - 本题要求一个左括号必须对应两个**连续**的右括号，所以还要检查 $s[i+1]$ 是不是右括号。如果是，那么跳过 $s[i+1]$，下一轮循环从 $i+2$ 开始；如果不是，必须补一个右括号（插在 $s[i]$ 和 $s[i+1]$ 之间）。

遍历结束后，如果 $\textit{left} > 0$（有未配对的左括号），那么补上 $\textit{left}\cdot 2$ 个右括号（可以插在 $s$ 末尾）。

```py [sol-Python3]
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        left = 0  # 未配对的左括号个数
        ans = i = 0

        while i < n:
            if s[i] == '(':
                left += 1  # 未配对的左括号
                i += 1
                continue

            if left > 0:
                left -= 1  # 左右括号配对
            else:
                ans += 1  # 右括号太多了，补一个左括号

            # 必须有两个连续的右括号，也就是 s[i+1] 必须也是右括号
            if i < n - 1 and s[i + 1] == ')':
                i += 2
            else:
                ans += 1  # 补一个右括号
                i += 1

        # 左括号太多了，补上缺失的右括号
        return ans + left * 2
```

class Solution {
    public int minInsertions(String S) {

        int n = s.length;
        int left = 0; // 未配对的左括号个数
        int ans = 0;

                continue;

                i++;

                ans++; // 补一个右括号
            }
        }

}
