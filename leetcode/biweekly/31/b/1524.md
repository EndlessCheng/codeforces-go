设 $\textit{arr}$ 的 [前缀和](https://leetcode.cn/problems/range-sum-query-immutable/solution/qian-zhui-he-ji-qi-kuo-zhan-fu-ti-dan-py-vaar/) 数组为 $s$，那么 $\textit{arr}$ 的子数组 $[\ell, r)$ 的和为 $s[r] - s[\ell]$。

于是问题变成：

- 对于长为 $n+1$ 的数组 $s$，有多少对 $(\ell,r)$ 满足 $0\le \ell < r\le n$ 且 $s[r] - s[\ell]$ 是奇数？

枚举 $r$，统计满足要求的 $\ell$ 的个数：

- 由于 $奇数 - 偶数 = 奇数$，如果 $s[r]$ 是奇数，我们需要知道左边有多少个 $s[\ell]$ 是偶数。
- 由于 $偶数 - 奇数 = 奇数$，如果 $s[r]$ 是偶数，我们需要知道左边有多少个 $s[\ell]$ 是奇数。

所以在遍历 $s$ 的过程中，要统计 $s[i]\bmod 2$ 的个数。

下面代码在计算 $s$ 的过程中取了模，这样做的正确性证明见 [模运算的世界：当加减乘除遇上取模](https://leetcode.cn/discuss/post/3584387/fen-xiang-gun-mo-yun-suan-de-shi-jie-dan-7xgu/)。

## 优化前

```py [sol-Python3]
class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        sums = [0] * (len(arr) + 1)
        for i, x in enumerate(arr):
            sums[i + 1] = (sums[i] + x) % 2

        # cnt[0] 统计偶数 s[i] 的个数
        # cnt[1] 统计奇数 s[i] 的个数
        cnt = [0] * 2
        ans = 0
        for s in sums:
            ans += cnt[s ^ 1]  # 在 s 左边的奇偶性不同于 s 的个数
            cnt[s] += 1
        return ans % 1_000_000_007
```

```java [sol-Java]
class Solution {
    public int numOfSubarrays(int[] arr) {
        final int MOD = 1_000_000_007;
        int[] sum = new int[arr.length + 1];
        for (int i = 0; i < arr.length; i++) {
            sum[i + 1] = (sum[i] + arr[i]) % 2;
        }

        // cnt[0] 统计偶数 s[i] 的个数
        // cnt[1] 统计奇数 s[i] 的个数
        int[] cnt = new int[2];
        long ans = 0;
        for (int s : sum) {
            ans += cnt[s ^ 1]; // 在 s 左边的奇偶性不同于 s 的个数
            cnt[s]++;
        }
        return (int) (ans % MOD);
    }
}
```

	for i, x := range arr {
		sum[i+1] = (sum[i] + x) % 2
	}

	// cnt[0] 统计偶数 s[i] 的个数
	// cnt[1] 统计奇数 s[i] 的个数
	cnt := [2]int{}

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n)$，其中 $n$ 是 $\textit{arr}$ 的长度。
- 空间复杂度：$\mathcal{O}(n)$。

## 优化

把两个循环合并为一个循环，一边算 $s$ 一边统计，这样 $s$ 可以简化成一个变量。

```py [sol-Python3]
class Solution:
    def numOfSubarrays(self, arr: list[int]) -> int:
        cnt = [1, 0]  # s[0] = 0 出现一次
        ans = s = 0
        for x in arr:
            s = (s + x) % 2
            ans += cnt[s ^ 1]
            cnt[s] += 1
        return ans % 1_000_000_007
```

```java [sol-Java]
class Solution {
    public int numOfSubarrays(int[] arr) {
        final int MOD = 1_000_000_007;
        int[] cnt = {1, 0}; // s[0] = 0 出现一次
        int s = 0;
        long ans = 0;
        for (int x : arr) {
            s = (s + x) & 1; // &1 比 %2 快
            ans += cnt[s ^ 1];
            cnt[s]++;
        }
        return (int) (ans % MOD);
    }
}
```
