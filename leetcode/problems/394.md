## 前言

首先明确输入的 $s$ 有哪些类型：

- **基础**：不含括号，所以也没有数字，此时 $s$ 只包含字母，例如 $s=\texttt{abc}$。
- **嵌套**：如题目所说，`k[encoded_string]`，即数字 + 左括号 + 括号中的字符串 + 右括号。
  - 例如 $s=\texttt{2[abc]}$，解码后是 $\texttt{abcabc}$。 
  - 例如 $s=\texttt{2[3[ab]]}$，内层的 $\texttt{3[ab]} = \texttt{ababab}$，所以 $\texttt{2[3[ab]]} = \texttt{2[ababab]} = \texttt{abababababab}$。
- **组合**：多个 `k[encoded_string]` 并在一起。
  - 例如 $s=\texttt{2[ab]3[xy]} = \texttt{2[ab]}+\texttt{3[xy]} = \texttt{abab} + \texttt{xyxyxy} = \texttt{ababxyxyxy}$。
  - 例如 $s=\texttt{ab2[cd]e} = \texttt{ab}+\texttt{2[cd]} + \texttt{e} = \texttt{ab}+\texttt{cdcd} + \texttt{e} = \texttt{abcdcde}$。

## 第一种递归写法

分类讨论：

- 如果 $s$ 是空串，返回空串。
- 如果 $s_0$ 是字母，我们可以递归解码 $s_1$ 到 $s_{n-1}$。
   - 如果 $s$ 是基础类型，例如 $s=\texttt{abc}$，那么 $\texttt{a} + \texttt{bc}$ 仍然是 $\texttt{abc}$。
   - 如果 $s$ 是组合类型，例如 $s=\texttt{ab2[cd]e}$，那么答案等于 $\texttt{a} + \texttt{b2[cd]e}$，后者可以继续递归解码。
- 否则，$s_0$ 一定是数字。这意味着 $s$ 至少包含一对括号。
   - 找第一个左括号的下标 $i$。
   - 找与 $s_i$ 匹配的右括号的下标 $j$。⚠**注意**：对于 $s=\texttt{2[3[ab]]}$ 这种嵌套类型，我们需要跳过内层的括号。可以用一个变量 $\textit{balance}$ 表示左括号减去右括号的个数，在遍历 $s$ 的过程中维护 $\textit{balance}$，一旦 $\textit{balance}=0$ 就表示我们找到了与第一个左括号匹配的右括号。
   - 把 $s$ 分成三部分：
      - $s_0$ 到 $s_{i-1}$ 转成数字 $k$。
      - $s_{i+1}$ 到 $s_{j-1}$ 继续递归解码，得到字符串 $a$。
      - $s_{j+1}$ 到 $s_{n-1}$ 继续递归解码，得到字符串 $b$。
   - 把 $a$ 重复 $k$ 次，再与 $b$ 拼接，得到答案 $a\cdot k + b$。

```py [sol-Python3]
class Solution:
    def decodeString(self, s: str) -> str:
        if not s:
            return s

        # s[0] 是字母
        if s[0].isalpha():
            # 分离出 s[0]，解码剩下的
            return s[0] + self.decodeString(s[1:])

        # s[0] 是数字，后面至少有一对括号
        i = s.find('[')  # 找左括号
        # 找右括号，注意对于 [...[...]...] 这种情况，第一个右括号并不是我们要找的，第二个才是
        balance = 1  # 左括号个数减去右括号个数
        for j in count(i + 1):  # 从 i+1 开始向右遍历，找与 s[i] 匹配的右括号
            if s[j] == '[':
                balance += 1
            elif s[j] == ']':
                balance -= 1
                if balance == 0:  # 左右括号个数相等，找到与 s[i] 匹配的右括号 s[j]
                    return self.decodeString(s[i + 1: j]) * int(s[:i]) + self.decodeString(s[j + 1:])
```

```java [sol-Java]
class Solution {
    public String decodeString(String s) {
        if (s.isEmpty()) {
            return s;
        }

        // s[0] 是字母
        if (Character.isLetter(s.charAt(0))) {
            // 分离出 s[0]，解码剩下的
            return s.charAt(0) + decodeString(s.substring(1));
        }

        // s[0] 是数字，后面至少有一对括号
        int i = s.indexOf('['); // 找左括号
        int balance = 1; // 左括号个数减去右括号个数
        for (int j = i + 1; ; j++) {
            char c = s.charAt(j);
            if (c == '[') {
                balance++;
            } else if (c == ']') {
                balance--;
                if (balance == 0) { // 找到与 s[i] 匹配的右括号 s[j]
                    int k = Integer.parseInt(s.substring(0, i));
                    String t = decodeString(s.substring(i + 1, j));
                    return new StringBuilder()
                            .repeat(t, k)
                            .append(decodeString(s.substring(j + 1)))
                            .toString();
                }
            }
        }
    }
}
```

```rust [sol-Rust]
impl Solution {
    pub fn decode_string(s: String) -> String {
        if s.is_empty() {
            return s;
        }

        let bs = s.as_bytes();
        // s[0] 是字母
        if bs[0].is_ascii_lowercase() {
            // 分离出 s[0]，解码剩下的
            return s[..1].to_string() + &Self::decode_string(s[1..].to_string());
        }

        // s[0] 是数字，后面至少有一对括号
        let i = s.find('[').unwrap(); // 找左括号
        let mut balance = 1; // 左括号个数减去右括号个数
        for j in i + 1.. {
            if bs[j] == b'[' {
                balance += 1;
            } else if bs[j] == b']' {
                balance -= 1;
                if balance == 0 { // 左右括号个数相等，找到与 s[i] 匹配的右括号 s[j]
                    let k = s[..i].parse().unwrap();
                    let t = Self::decode_string(s[i + 1..j].to_string());
                    return t.repeat(k) + &Self::decode_string(s[j + 1..].to_string());
                }
            }
        }
        unreachable!()
    }
}
```

- 时间复杂度：$\mathcal{O}(U^m)$，其中 $U\le 300$ 为 $k$ 的最大值，$m=\mathcal{O}\left(\dfrac{n}{\log U}\right)$，$n$ 是 $s$ 的长度。最坏情况下 $s$ 形如 $\texttt{300[300[...[300[a]]...]]}$，嵌套 $m=\mathcal{O}\left(\dfrac{n}{\log U}\right)$ 层，生成的字符串长度为 $300\times 300\times \dots \times 300 = 300^m$。不过，本题保证答案长度不超过 $10^5$。

## 第二种递归写法

把 $s$ 视作若干基础字符串和 `k[encoded_string]` 的并。

以 $s=\texttt{ab2[cd]3[e]}$ 为例说明，将其视作 $\texttt{ab} + \texttt{2[cd]} + \texttt{3[e]}$。从左到右遍历 $s$：

1. $s_0=\texttt{a}$，加到答案中，现在答案为 $\texttt{a}$。
2. $s_1=\texttt{b}$，加到答案中，现在答案为 $\texttt{ab}$。
3. $s_2=\texttt{2}$，更新重复次数 $k=2$。
4. $s_3=\texttt{[}$，往下递归。
5. $s_4=\texttt{c}$，在下一级递归函数中的字符串为 $\texttt{c}$。
6. $s_5=\texttt{d}$，在下一级递归函数中的字符串为 $\texttt{cd}$。
7. $s_6=\texttt{]}$，递归返回 $\texttt{cd}$。上层递归函数接收到 $\texttt{cd}$，将其重复 $k=2$ 次，得到 $\texttt{cdcd}$，加到答案中，现在答案为 $\texttt{abcdcd}$。然后重置 $k=0$。⚠**注意**：如果不重置，后面遍历到数字 $3$ 的时候，会把 $3$ 加到 $2$ 的后面，得到错误的 $k=23$。
8. $s_7=\texttt{3}$，更新重复次数 $k=3$。
9. $s_{8,9,10}=\texttt{[e]}$，和上面一样，递归，得到字符串 $\texttt{e}$。将其重复 $k=3$ 次，得到 $\texttt{eee}$，加到答案中，最终答案为 $\texttt{abcdcdeee}$。

#### 细节

**问**：递归过程中，怎么知道当前遍历到哪个字符了？

**答**：可以用一个在递归函数外的变量 $i$ 表示当前下标，每遍历到一个字符，就把 $i$ 加一。

**问**：如果 $s=\texttt{123[a]}$，怎么把字符串 $\texttt{123}$ 变成数字 $k=123$？

**答**：利用式子 $k = k\cdot 10 + \texttt{int}(s_i)$ 计算。

- 初始化 $k=0$。
- 更新 $k$ 为 $k\cdot 10 + 1 = 0 + 1 = 1$。
- 更新 $k$ 为 $k\cdot 10 + 2 = 10 + 2 = 12$。
- 更新 $k$ 为 $k\cdot 10 + 3 = 120 + 3 = 123$。

```py [sol-Python3]
class Solution:
    def decodeString(self, s: str) -> str:
        i = 0

        def decode() -> str:
            nonlocal i
            res = ''  # 或者 res = []，具体见另一份代码【Python3 列表】
            k = 0
            while i < len(s):
                c = s[i]
                i += 1
                if c.isalpha():
                    res += c
                elif c.isdigit():
                    k = k * 10 + int(c)
                elif c == '[':  # 递
                    res += decode() * k  # 把括号内的字符串重复 k 次
                    k = 0  # 重置 k，若不重置，2[a]3[b] 后面的 3 会算出 k = 23
                else:  # ']' 归
                    break
            return res

        return decode()
```

```rust [sol-Rust]
impl Solution {
    pub fn decode_string(s: String) -> String {
        fn decode(s: &[u8], i: &mut usize) -> String {
            let mut res = String::new();
            let mut k = 0;
            while *i < s.len() {
                let c = s[*i];
                *i += 1;
                if c.is_ascii_lowercase() {

                } else if c.is_ascii_digit() {
```

## 用栈模拟递归

把第二种递归改写成非递归写法。

首先你要理解计算机底层是如何实现递归的，请看视频 [深刻理解递归【基础算法精讲 09】](https://www.bilibili.com/video/BV1UD4y1Y769/)。

简单来说，在往下「递」的时候，计算机会把当前函数中的局部变量保存到栈中；下层递归函数「归」之后，再从栈中把保存的变量取出。我们可以手动模拟这个过程，具体实现如下。

```py [sol-Python3]
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []  # 用于模拟计算机的递归
        res = ''
        k = 0
        for c in s:
            if c.isalpha():
                res += c
            elif c.isdigit():
                k = k * 10 + int(c)
            elif c == '[':
                # 模拟递归
                # 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
                stack.append((res, k))
                # 递归，初始化 res 和 k
                res = ''
                k = 0
            else:  # ']'
                # 递归结束，从栈中恢复递归之前保存的局部变量
                pre_res, pre_k = stack.pop()
                # 此时 res 是下层递归的返回值，将其重复 pre_k 次，拼接到递归前的 pre_res 之后
                res = pre_res + res * pre_k
        return res
```

```java [sol-Java]
class Solution {
    private record Pair(String s, int k) {
    }

    public String decodeString(String s) {
        Deque<Pair> stack = new ArrayDeque<>(); // 用于模拟计算机的递归
        StringBuilder res = new StringBuilder();
        int k = 0;
        for (char c : s.toCharArray()) {
            if (Character.isLetter(c)) {
                res.append(c);
            } else if (Character.isDigit(c)) {
                k = k * 10 + (c - '0');
            } else if (c == '[') {
                // 模拟递归
                // 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
                stack.push(new Pair(res.toString(), k));
                // 递归，初始化 res 和 k
                res.setLength(0);
                k = 0;
            } else { // ']'
                // 递归结束，从栈中恢复递归之前保存的局部变量
                Pair p = stack.pop();
                // 此时 res 是下层递归的返回值，将其重复 p.k 次，拼接到递归前的 p.s 之后
                res = new StringBuilder(p.s).repeat(res, p.k);
            }
        }
        return res.toString();
    }
}
```

```cpp [sol-C++]
class Solution {
public:
    string decodeString(string s) {
        stack<pair<string, int>> stk; // 用于模拟计算机的递归
        string res;
        int k = 0;
        for (char c : s) {
            if (isalpha(c)) {
                res += c;
            } else if (isdigit(c)) {
                k = k * 10 + (c - '0');
            } else if (c == '[') {
                // 模拟递归
                // 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
                stk.emplace(move(res), k);
                // 递归，初始化 res 和 k（由于 move 了，res 此时为空）
                k = 0;
            } else { // ']'
                // 递归结束，从栈中恢复递归之前保存的局部变量
                auto [pre_res, pre_k] = stk.top();
                stk.pop();
                // 此时 res 是下层递归的返回值，将其重复 pre_k 次，拼接到递归前的 pre_res 之后
                while (pre_k--) {
                    pre_res += res;
                }
                res = move(pre_res);
            }
        }
        return res;
    }
};
```

```go [sol-Go]
    type pair struct {
        s string
        k int
    }
    stack := []pair{} // 用于模拟计算机的递归
    res := ""
    k := 0
    for _, c := range s {

            // 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
            stack = append(stack, pair{res, k})
            // 递归，初始化 res 和 k
            res = ""
            k = 0
        } else { // ']'
            // 递归结束，从栈中恢复递归之前保存的局部变量
            p := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            // 此时 res 是下层递归的返回值，将其重复 p.k 次，拼接到递归前的 p.s 之后
            res = p.s + strings.Repeat(res, p.k)
        }
    }
    return res
}
```

```js [sol-JavaScript]
var decodeString = function(s) {
    const stack = []; // 用于模拟计算机的递归
    let res = '';
    let k = 0;
    for (const c of s) {
        if ('a' <= c && c <= 'z') {
            res += c;
        } else if ('0' <= c && c <= '9') {
            k = k * 10 + parseInt(c);
        } else if (c === '[') {
            // 模拟递归
            // 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
            stack.push([res, k]);
            // 递归，初始化 res 和 k
            res = '';
            k = 0;
        } else { // ']'
            // 递归结束，从栈中恢复递归之前保存的局部变量
            const [pre_res, pre_k] = stack.pop();
            // 此时 res 是下层递归的返回值，将其重复 pre_k 次，拼接到递归前的 pre_res 之后
            res = pre_res + res.repeat(pre_k);
        }
    }
    return res;
};
```

```rust [sol-Rust]
impl Solution {
    pub fn decode_string(s: String) -> String {
        let mut stack = vec![]; // 用于模拟计算机的递归
        let mut res = String::new();
        let mut k = 0;
        for c in s.bytes() {
            if c.is_ascii_lowercase() {
                res.push(c as char);
            } else if c.is_ascii_digit() {
                k = k * 10 + (c - b'0') as usize;
            } else if c == b'[' {
                // 模拟递归
                // 在递归之前，把当前递归函数中的局部变量 res 和 k 保存到栈中
                stack.push((res.clone(), k));
                // 递归，初始化 res 和 k
                res.clear();
                k = 0;
            } else { // ']'
                // 递归结束，从栈中恢复递归之前保存的局部变量
                let (pre_res, pre_k) = stack.pop().unwrap();
                // 此时 res 是下层递归的返回值，将其重复 pre_k 次，拼接到递归前的 pre_res 之后
                res = pre_res + &res.repeat(pre_k);
            }
        }
        res
    }
}
```
