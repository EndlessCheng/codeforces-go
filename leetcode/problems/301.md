## 方法一：BFS

对于字符串 $x$，设删除 $x$ 的一个括号后的字符串为 $y$，连一条从 $x$ 到 $y$ 的有向边，我们可以得到一张有向图。

问题等价于：

- 在有向图中找到距离起点 $s$ **最近**的所有有效括号字符串。

这可以用 **BFS** 解决。下面代码用双集合实现 BFS，原理请看[【基础算法精讲 13】](https://www.bilibili.com/video/BV1hG4y1277i/)。

本题每走一步，字符串的长度就减少一（越来越短），所以有向图无环，无需 $\textit{vis}$ 标记。

```py [sol-Python3]
class Solution:
    def removeInvalidParentheses(self, s: str) -> list[str]:
        def is_valid(s: str) -> bool:
            left = 0  # 未配对的左括号的个数
            for ch in s:
                if ch == '(':
                    left += 1
                elif ch == ')':
                    if left == 0:  # 右括号太多了
                        return False
                    left -= 1  # 左右括号配对
            return left == 0  # 所有左括号都要有对应的右括号

        cur = {s}  # 起点
        while True:
            ans = [t for t in cur if is_valid(t)]
            if ans:  # cur 中存在有效括号字符串
                return ans

            nxt = set()
            for t in cur:
                # 枚举删除 t[i]
                for i, ch in enumerate(t):
                    if ch == '(' or ch == ')':
                        nxt.add(t[:i] + t[i + 1:])
            cur = nxt
```

```java [sol-Java]
        HashSet<String> cur = new HashSet<>();

                }

                    }
                }
            }
            cur = nxt;
        }

                }
                left--; // 左右括号配对
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(nm2^m)$，其中 $n$ 是 $s$ 的长度，$m\le 20$ 是 $s$ 中的括号个数。最坏情况下，所有括号都要删除。BFS 过程会枚举 $m$ 个括号的所有子集，这有 $2^m$ 个，所以有向图有 $\mathcal{O}(2^m)$ 个节点。每个节点枚举了 $\mathcal{O}(m)$ 个括号，生成了 $\mathcal{O}(m)$ 个长为 $\mathcal{O}(n)$ 的新字符串，所以处理每个节点需要 $\mathcal{O}(nm)$ 的时间。所以总的时间复杂度为 $\mathcal{O}(nm2^m)$。
- 空间复杂度：$\mathcal{O}\left(\dfrac{n2^m}{\sqrt m}\right)$。当 BFS 执行到删除 $m/2$ 个括号的那一层时，$\textit{cur}$ 的大小最大，需要 $\mathcal{O}(n\binom m {m/2}) = \mathcal{O}\left(\dfrac{n2^m}{\sqrt m}\right)$ 的空间。

## 方法二：回溯

先计算最少要删除的括号个数。或者说，保留的左右括号的个数最多是多少。

在从左到右遍历 $s$ 的过程中，维护未配对的左括号的个数 $\textit{left}$。

- 如果 $s[i]$ 是左括号，那么 $\textit{left}$ 增加一。
- 如果 $s[i]$ 是右括号：
    - 如果 $\textit{left} = 0$，说明右括号太多了，那么 $s[i]$ 或者左边的某个右括号必须删除。
    - 否则，左右括号配对，把 $\textit{left}$ 减少一。

遍历结束后，如果 $\textit{left} > 0$，说明有 $\textit{left}$ 个多余的左括号必须删除。

设 $s$ 中一共有 $t$ 个左括号，设 $\textit{target} = t - \textit{left}$，问题等价于：

- 从 $s$ 中恰好选 $\textit{target}$ 个左括号和 $\textit{target}$ 个右括号（字母保留）。
- 这 $2\cdot \textit{target}$ 个括号必须组成合法括号字符串，字符串任意前缀中的左括号的个数不能低于右括号的个数。

这是「组合型回溯」。注意避免重复枚举，比如一对相邻的左括号，删除左边的左括号还是右边的左括号，结果是一样的。所以本题是「**有重复元素的组合型回溯**」，做法类似 [40. 组合总和 II](https://leetcode.cn/problems/combination-sum-ii/)，请看 [我的题解](https://leetcode.cn/problems/combination-sum-ii/solutions/3036036/liang-chong-fang-fa-xuan-huo-bu-xuan-mei-a7be/)。

### 写法一：选或不选

```py [sol-Python3]
class Solution:
    def removeInvalidParentheses(self, s: str) -> list[str]:
        target = left = 0
        for ch in s:
            if ch == '(':
                target += 1
                left += 1
            elif ch == ')' and left > 0:
                left -= 1
        target -= left  # 移除多余的 left 个左括号

        n = len(s)
        ans = []
        path = []

        # 当前枚举到 s[i]，已选 left 个左括号和 right 个右括号
        def dfs(i: int, left: int, right: int) -> None:
            # 剪枝（最后一个判断条件是剩余字符个数不足以让我们选出 target*2 个括号）
            if left < right or left > target or left + right + n - i < target * 2:
                return

            if i == n:  # 上面剪枝了，这里一定选了 target 个左右括号
                ans.append(''.join(path))
                return

            ch = s[i]

            # 不选 ch
            if ch == '(' or ch == ')':
                # 后面所有等于 ch 的括号都不选
                # 如果不跳过这些括号，会导致「选 ch 不选 ch'」和「不选 ch 选 ch'」这两种情况都会加到 ans 中，这就重复了
                j = i + 1
                while j < n and s[j] == ch:
                    j += 1
                dfs(j, left, right)

            # 选 ch
            if ch == '(':
                left += 1
            elif ch == ')':
                right += 1
            path.append(ch)
            dfs(i + 1, left, right)
            path.pop()  # 恢复现场

        dfs(0, 0, 0)
        return ans
```

```py [sol-Python3]
class Solution:
    def removeInvalidParentheses(self, s: str) -> list[str]:
        target = left = alpha = 0
        for ch in s:
            if ch == '(':
                target += 1
                left += 1
            elif ch == ')':
                left = max(left - 1, 0)
            else:
                alpha += 1
        target -= left  # 移除多余的 left 个左括号
        total_length = target * 2 + alpha

        n = len(s)
        ans = []
        path = []

        # 当前枚举到 s[i]，已选 left 个左括号和 right 个右括号
        def dfs(i: int, left: int, right: int) -> None:
            # 剪枝（最后一个判断条件是剩余字符个数不足以让我们选出 target*2 个括号）
            if left < right or left > target or left + right + n - i < target * 2:
                return

            if len(path) == total_length:  # 上面剪枝了，此时 path 一定合法
                ans.append(''.join(path))
                return

            # 在 [i,n-1] 中选一个 s[j]
            # 注意选 s[j] 意味着 [i,j-1] 中的字符都没有选
            for j in range(i, n):
                # 考虑选 s[j]
                # 如果 j>i，说明 s[j-1] 没有选
                # 同方法一，所有等于 s[j-1] 的字符都不选
                ch = s[j]
                if j > i and ch == s[j - 1]:
                    continue
                path.append(ch)
                dfs(j + 1, left + (ch == '('), right + (ch == ')'))
                path.pop()  # 恢复现场
                if ch != '(' and ch != ')':
                    break  # 字母必须选

        dfs(0, 0, 0)
        return ans
```

```go [sol-Go]
			path = path[:len(path)-1] // 恢复现场
			if ch != '(' && ch != ')' {
				break // 字母必须选
			}
		}
	}

	dfs(0, 0, 0)
	return ans
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n2^m)$，其中 $n$ 是 $s$ 的长度，$m\le 20$ 是 $s$ 中的括号个数。
- 空间复杂度：$\mathcal{O}(n)$。返回值不计入。

**注**：本题括号之间存在字母，不能用卡特兰数分析时间复杂度。例如 $s = \texttt{(a(b(c))}$，只看括号的话，这几个左括号删除哪一个都一样，都能得到 $\texttt{(())}$。但由于字母的存在，删除不同位置的括号，得到的字符串是不一样的。
