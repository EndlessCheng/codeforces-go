## 方法一：记忆化搜索

$\textit{dfs}(i)$ 表示以 $\textit{nums}[i]$ 结尾的最长递增子序列（LIS）的长度。

枚举子序列的倒数第二个数的下标是 $j$，如果 $\textit{nums}[j] < \textit{nums}[i]$，那么有

$$
\textit{dfs}(i) = \textit{dfs}(j) + 1
$$

取最大值。

注意 $\textit{nums}[i]$ 可以单独形成一个长为 $1$ 的子序列。

### 答疑

**问**：什么样的题目适合「选或不选」，什么样的题目适合「枚举选哪个」？

**答**：我分成两类问题：

- 相邻无关子序列问题（比如 0-1 背包），适合「**选或不选**」。每个元素互相独立，只需依次考虑每个元素选或不选。
- 相邻相关子序列问题（比如本题），适合「**枚举选哪个**」。我们需要知道子序列中的相邻两个数的关系。对于本题来说，枚举 $\textit{nums}[i]$ 必选，然后枚举前一个必选的数，方便比大小。如果硬要用「选或不选」，需要额外记录上一个选的数的下标，算法总体的空间复杂度为 $\mathcal{O}(n^2)$，而枚举选哪个只需要 $\mathcal{O}(n)$ 的空间。

```py [sol-Python3]
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        @cache
        def dfs(i: int) -> int:
            res = 0
            for j in range(i):
                if nums[j] < nums[i]:
                    res = max(res, dfs(j))
            return res + 1  # 加一提到循环外面

        return max(dfs(i) for i in range(len(nums)))
```

```java [sol-Java]
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] memo = new int[n]; // 本题可以初始化成 0，表示没有计算过
        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, dfs(i, nums, memo));
        }
        return ans;
    }

    private int dfs(int i, int[] nums, int[] memo) {
        if (memo[i] > 0) { // 之前计算过
            return memo[i];
        }
        int res = 0;
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                res = Math.max(res, dfs(j, nums, memo));
            }
        }
        res++; // 加一提到循环外面
        return memo[i] = res;
    }
}
```

```go [sol-Go]
func lengthOfLIS(nums []int) (ans int) {
    n := len(nums)
    memo := make([]int, n) // 本题可以初始化成 0，表示没有计算过

    var dfs func(int) int
    dfs = func(i int) int {
        p := &memo[i]
        if *p > 0 {
            return *p
        }
        res := 0
        for j, x := range nums[:i] {
            if x < nums[i] {
                res = max(res, dfs(j))
            }
        }
        res++ // 加一提到循环外面
        *p = res
        return res
    }

    for i := range n {
        ans = max(ans, dfs(i))
    }
    return
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n^2)$，其中 $n$ 为 $\textit{nums}$ 的长度。由于每个状态只会计算一次，动态规划的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题中状态个数等于 $\mathcal{O}(n)$，单个状态的计算时间为 $\mathcal{O}(n)$，所以动态规划的时间复杂度为 $\mathcal{O}(n^2)$。
- 空间复杂度：$\mathcal{O}(n)$。保存多少状态，就需要多少空间。

## 方法二：递推

同记忆化搜索，$f[i]$ 表示以 $\textit{nums}[i]$ 结尾的最长递增子序列（LIS）的长度。

```py [sol-Python3]
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        f = [0] * len(nums)
        for i, x in enumerate(nums):
            for j, y in enumerate(nums[:i]):
                if x > y:
                    f[i] = max(f[i], f[j])
            f[i] += 1
        return max(f)
```

```java [sol-Java]
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length, ans = 0;
        int[] f = new int[n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    f[i] = Math.max(f[i], f[j]);
                }
            }
            ans = Math.max(ans, ++f[i]);
        }
        return ans;
    }
}
```

## 方法三：贪心 + 二分查找

> **注**：方法三本质是对上述 DP 做法的优化，也算 DP 做法。

假设 $f[3]$ 和 $f[4]$ 的值都等于 $2$，且 $\textit{nums}[3]=99999$，$\textit{nums}[4]=9$。

我们现在要计算 $f[5]$。想一想，谁**更容易**满足上面代码中的 `if (nums[j] < nums[i])`？这里 $i=5$，$j=3$ 或者 $4$。

$\textit{nums}[4]$ 更小，更容易满足 `if (nums[j] < nums[i])`。更大的 $\textit{nums}[3]$ 虽然也可能满足条件，但由于 $f[3]=f[4]$，在更新 $f[5]$ 时，**二者的效果是一样的**，所以 $\textit{nums}[3]$ 是个无用数据。换句话说，对于相同的 $f$ 值，我们**只需保留更小的** $\textit{nums}[i]$。

> **注**：这个「去掉无用数据」的想法和**单调栈**是一样的。见 [单调栈【基础算法精讲 26】](https://www.bilibili.com/video/BV1VN411J7S7/)。

因此，定义 $g[i]$ 表示 $f[j]=i+1$ 时，$\textit{nums}[j]$ 的**最小值**。也就是长为 $i+1$ 的上升子序列的末尾元素的最小值。这里 $+1$ 是因为 $f[j]$ 至少是 $1$，$g[0]$ 对应的不是 $f[j]=0$，而是 $f[j]=1$。

关于 $g$ 数组的性质，请看 [最长递增子序列【基础算法精讲 20】](https://www.bilibili.com/video/BV1ub411Q7sB/)。

#### 写法一：额外空间

```py [sol-Python3]
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        g = []
        for x in nums:
            j = bisect_left(g, x)
            if j == len(g):  # >=x 的 g[j] 不存在
                g.append(x)
            else:
                g[j] = x
        return len(g)
```

```java [sol-Java]
class Solution {
    public int lengthOfLIS(int[] nums) {
        List<Integer> g = new ArrayList<>();
        for (int x : nums) {
            int j = lowerBound(g, x);
            if (j == g.size()) {
                g.add(x); // >=x 的 g[j] 不存在
            } else {
                g.set(j, x);
            }
        }
        return g.size();
    }

    // 开区间写法
    private int lowerBound(List<Integer> g, int target) {
        int left = -1, right = g.size(); // 开区间 (left, right)
        while (left + 1 < right) { // 区间不为空
            // 循环不变量：
            // nums[left] < target
            // nums[right] >= target
            int mid = left + (right - left) / 2;
            if (g.get(mid) < target) {
                left = mid; // 范围缩小到 (mid, right)
            } else {
                right = mid; // 范围缩小到 (left, mid)
            }
        }
        return right; // 或者 left+1
    }
}
```

## 附：返回一个具体的 LIS

```py [sol-Python3]
class Solution:
    def findOneLIS(self, nums: List[int]) -> List[int]:
        if not nums:
            return []

        n = len(nums)
        g = []  # 不仅记录值，还记录值对应的下标
        last = [-1] * n

        for i, x in enumerate(nums):
            j = bisect_left(g, x, key=lambda t: t[0])
            if j > 0:
                last[i] = g[j - 1][1]  # 记录 nums[i] 添加到了哪个数的末尾
            if j < len(g):
                g[j] = (x, i)  # 额外保存下标
            else:
                g.append((x, i))

        lis = []
        i = g[-1][1]  # LIS 的最后一个数是 nums[g[-1][1]]
        while i >= 0:
            lis.append(nums[i])
            i = last[i]  # 顺着 last 倒着找上一个数
        lis.reverse()
        return lis
```

```java [sol-Java]
class Solution {
    public List<Integer> findOneLis(int[] nums) {
        int n = nums.length;
        if (n == 0) {
            return List.of();
        }

        List<int[]> g = new ArrayList<>(); // 不仅记录值，还记录值对应的下标
        int[] last = new int[n];
        Arrays.fill(last, -1);

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            int j = lowerBound(g, x);
            if (j > 0) {
                last[i] = g.get(j - 1)[1]; // 记录 nums[i] 添加到了哪个数的末尾
            }
            if (j < g.size()) {
                g.set(j, new int[]{x, i}); // 额外保存下标
            } else {
                g.add(new int[]{x, i});
            }
        }

        List<Integer> lis = new ArrayList<>();
        // LIS 的最后一个数是 nums[g.getLast()[1]]，顺着 last 倒着找上一个数
        for (int i = g.getLast()[1]; i >= 0; i = last[i]) {
            lis.add(nums[i]);
        }
        Collections.reverse(lis);
        return lis;
    }

    private int lowerBound(List<int[]> g, int target) {
        int left = -1;
        int right = g.size(); // 开区间 (left, right)
        while (left + 1 < right) { // 开区间不为空
            // 循环不变量：
            // g[right][0] >= target
            // g[left][0] < target
            int mid = left + (right - left) / 2;
            if (g.get(mid)[0] >= target) {
                right = mid; // 范围缩小到 (left, mid)
            } else {
                left = mid; // 范围缩小到 (mid, right)
            }
        }
        return right;
    }
}
```

```cpp [sol-C++]
class Solution {
public:
    vector<int> findOneLis(vector<int>& nums) {
        if (nums.empty()) {
            return {};
        }

        int n = nums.size();
        vector<pair<int, int>> g; // 不仅记录值，还记录值对应的下标
        vector<int> last(n, -1);

        for (int i = 0; i < n; i++) {
            int x = nums[i];
            int j = ranges::lower_bound(g, x, {}, &pair<int, int>::first) - g.begin();
            if (j > 0) {
                last[i] = g[j - 1].second; // 记录 nums[i] 添加到了哪个数的末尾
            }
            if (j < g.size()) {
                g[j] = {x, i}; // 额外保存下标
            } else {
                g.emplace_back(x, i);
            }
        }

        vector<int> lis;
        // LIS 的最后一个数是 nums[g.back().second]，顺着 last 倒着找上一个数
        for (int i = g.back().second; i >= 0; i = last[i]) {
            lis.push_back(nums[i]);
        }
        ranges::reverse(lis);
        return lis;
    }
};
```

```go [sol-Go]
func findOneLIS(nums []int) (lis []int) {
	n := len(nums)
	if n == 0 {
		return
	}

	type pair struct{ v, i int }
	g := []pair{} // 不仅记录值，还记录值对应的下标
	last := make([]int, n)
	for i := range last {
		last[i] = -1
	}

	for i, x := range nums {
		j := sort.Search(len(g), func(j int) bool { return g[j].v >= x })
		if j > 0 {
			last[i] = g[j-1].i // 记录 nums[i] 添加到了哪个数的末尾
		}
		if j < len(g) {
			g[j] = pair{x, i} // 额外保存下标
		} else {
			g = append(g, pair{x, i})
		}
	}

	// LIS 的最后一个数是 nums[g[len(g)-1].i]，顺着 last 倒着找上一个数
	for i := g[len(g)-1].i; i >= 0; i = last[i] {
		lis = append(lis, nums[i])
	}
	slices.Reverse(lis)
	return
}
```

- 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 为 $\textit{nums}$ 的长度。
- 空间复杂度：$\mathcal{O}(n)$。
