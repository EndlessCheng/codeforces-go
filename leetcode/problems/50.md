## 方法一：迭代

![lc50-4-c.png](https://pic.leetcode.cn/1790814796-YBMEbV-lc50-4-c.png){:width=620px}

当 $n<0$ 时，$x^n = (x^{-1})^{-n} = \left(\dfrac{1}{x}\right)^{-n} = \dfrac{1}{x^{-n}}$。分母的幂次 $-n > 0$，这样就可以复用上面的逻辑了。

⚠部分语言需要注意，当 $n=-2^{31}$ 时，$-n=2^{31}$ 比 $32$ 位整数的最大值还大，溢出了。可以转成 $64$ 位整数解决。

```py [sol-Python3]
class Solution:
    def myPow(self, x: float, n: int) -> float:
        def power(x: float, n: int) -> float:
            res = 1.0
            while n:  # 从低到高枚举 n 的每个比特位
                if n & 1:  # 这个比特位是 1
                    res *= x  # 把 x 乘到 res 中
                x *= x  # x 自身平方
                n >>= 1  # 继续枚举下一个比特位
            return res

        if n >= 0:
            return power(x, n)
        return 1.0 / power(x, -n)
```

}

## 方法二：递归

当 $n\ge 0$ 时，我们有

$$
x^n =
\begin{cases}
(x^{n/2})^2, & n\bmod 2 = 0     \\
(x^{\lfloor n/2\rfloor})^2\cdot x, & n\bmod 2 = 1     \\
\end{cases}
$$

根据上式递归计算 $x^n$。

递归边界：$x^0 = 1$。

```py [sol-Python3]
class Solution:
    def myPow(self, x: float, n: int) -> float:
        def power(x: float, n: int) -> float:
            if n == 0:
                return 1.0
            p = power(x, n // 2)
            return p * p * (x if n % 2 else 1.0)

        if n >= 0:
            return power(x, n)
        return 1.0 / power(x, -n)
```

```java [sol-Java]
class Solution {
    public double myPow(double x, int n) {
        if (n >= 0) {
            return power(x, n);
        }
        return 1 / power(x, -(long) n);
    }

    private double power(double x, long n) {
        if (n == 0) {
            return 1;
        }
        double res = power(x, n / 2);
        res *= res;
        if (n % 2 != 0) {
            res *= x;
        }
        return res;
    }
}
```
