讨论选的三个数包含多少个负数：

- 包含 $0$ 个负数：三个非负数相乘，数值越大，乘积越大，所以选 $\textit{nums}$ 中最大的三个数是最优的。
- 包含 $2$ 个负数：由于负负得正，选 $\textit{nums}$ 中最小的两个数以及最大的一个数是最优的。
- 包含 $1$ 个负数：这种情况乘积是非正数，应当选绝对值最小的负数，以及两个最小的非负数。如果这种选法是最优的，则说明 $\textit{nums}$ 中恰好有两个非负数（如果至少有三个非负数，那么选三个非负数更好）。此时「选绝对值最小的负数，以及两个最小的非负数」等价于「选 $\textit{nums}$ 中最大的三个数」。
- 包含 $3$ 个负数：这种情况乘积是负数，应当选绝对值最小的三个负数。如果这种选法是最优的，则说明 $\textit{nums}$ 中都是负数（如果有非负数，那么选一个非负数和两个负数，乘积是非负数，更优）。此时绝对值最小的三个负数即为最大的三个数。

综上所述，只需考虑两种情况：

1. 选 $\textit{nums}$ 中最大的三个数。
2. 选 $\textit{nums}$ 中最小的两个数以及最大的一个数。

> 注：题目保证 $\textit{nums}$ 至少有三个数。

## 写法一：排序

```py [sol-Python3]
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        nums.sort()
        return max(nums[-3] * nums[-2] * nums[-1], nums[0] * nums[1] * nums[-1])
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(n\log n)$，其中 $n$ 是 $\textit{nums}$ 的长度。瓶颈在排序上。
- 空间复杂度：$\mathcal{O}(1)$。忽略排序的栈开销。

## 写法二：一次遍历

```py [sol-Python3]
class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        min1 = min2 = inf
        max1 = max2 = max3 = -inf

        for x in nums:
            # 维护最小值和次小值
            if x < min1:
                min2 = min1
                min1 = x
            elif x < min2:
                min2 = x

            # 维护前三大
            if x > max1:
                max3 = max2
                max2 = max1
                max1 = x
            elif x > max2:
                max3 = max2
                max2 = x
            elif x > max3:
                max3 = x

        return max(max1 * max2 * max3, min1 * min2 * max1)
```
