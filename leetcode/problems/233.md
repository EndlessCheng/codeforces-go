## 方法一：数位 DP

### 写法一：把 1 的个数作为参数

**前置知识**：[数位 DP 模板讲解](https://www.bilibili.com/video/BV1rS4y1s721/?t=19m36s)

为方便计算，首先把 $n$ 转换成字符串 $s$。

定义 $\textit{dfs}(i,\textit{cnt}_1, \textit{isLimit})$ 表示在前 $i$ 位有 $\textit{cnt}_1$ 个 $1$ 的前提下，我们能构造出的数中的 $1$ 的个数总和。

例如 $n=9999$，如果前三位我们都填了 $1$，那么填到最后一位，此时 $\textit{dfs}$ 计算的就是 $1110,1111,1112,\ldots,1119$ 这 $10$ 个数中一共有多少个 $1$（一共有 $31$ 个 $1$）。

$\textit{dfs}$ 中的 $\textit{isLimit}$ 表示当前是否受到了 $n$ 的约束（我们要构造的数字不能超过 $\textit{n}$）。若为真，则第 $i$ 位填入的数字至多为 $\textit{n}[i]$，否则至多为 $9$，把这个上限记作 $\textit{up}$。如果在受到约束的情况下填了数字 $\textit{up}$，那么后续填入的数字仍会受到 $\textit{n}$ 的约束。例如 $\textit{n}=123$，那么 $i=0$ 填的是 $1$ 的话，$i=1$ 的这一位至多填 $2$。

**递归边界**：当所有数字填完时，返回 $\textit{cnt}_1$。

**递归入口**：$\textit{dfs}(0,0,\texttt{true})$，一开始没有填数字，并且会受到 $n$ 的约束。

#### 答疑

**问**：记忆化三个状态有点麻烦，可以不记录 $\textit{isLimit}$ 吗？

**答**：可以。想一想 $\textit{isLimit}=\texttt{true}$ 只在什么情况下成立？只在我们填入的数字都等于 $n$ 对应位置的数字时成立。比如 $\textit{n}=234$，第一位填 $2$，第二位填 $3$，此时 $\textit{isLimit}=\texttt{true}$。但我们不会再次递归到第一位填 $2$，第二位填 $3$ 的情况，记忆化这样的状态是没有意义的。（注：想象我们在写一个三重循环，去枚举每一位填什么数字。第一位填 $2$，第二位填 $3$ 已经是快要结束循环的情况了，不可能再次枚举到。）

根据这个例子，我们可以只记录不受到 $n$ 约束时的状态 $(i, \textit{cnt}_1)$。相当于记忆化的是 $(i,\textit{cnt}_1,\texttt{false})$ 这个状态。比如 $\textit{n}=234$，第一位填 $1$，第二位填 $2$，或者第一位填 $2$，第二位填 $1$，都会递归到 $(2,1,\texttt{false})$ 这个状态，那么第二次递归到这个状态时，就可以直接返回第一次递归记忆化的结果了。

```py [sol-Python3]
class Solution:
    def countDigitOne(self, n: int) -> int:
        s = list(map(int, str(n)))  # 避免在 dfs 中频繁调用 int()

        @cache  # 缓存装饰器，避免重复计算 dfs 的结果（一行代码实现记忆化）
        def dfs(i: int, cnt1: int, is_limit: bool) -> int:
            if i == len(s):
                return cnt1

            up = s[i] if is_limit else 9
            res = 0
            for d in range(up + 1):  # 枚举要填入的数字 d
                res += dfs(i + 1, cnt1 + (d == 1), is_limit and d == up)

            return res

        return dfs(0, 0, True)
```

```java [sol-Java]
class Solution {
    public int countDigitOne(int n) {
        char[] s = Integer.toString(n).toCharArray();
        int m = s.length;
        int[][] memo = new int[m][m];
        for (int[] row : memo) {
            Arrays.fill(row, -1); // -1 表示没有计算过
        }
        return dfs(0, 0, true, s, memo);
    }

    private int dfs(int i, int cnt1, boolean isLimit, char[] s, int[][] memo) {
        if (i == s.length) {
            return cnt1;
        }
        if (!isLimit && memo[i][cnt1] >= 0) { // 之前计算过
            return memo[i][cnt1];
        }

        int up = isLimit ? s[i] - '0' : 9;
        int res = 0;
        for (int d = 0; d <= up; d++) { // 枚举要填入的数字 d
            res += dfs(i + 1, cnt1 + (d == 1 ? 1 : 0), isLimit && d == up, s, memo);
        }

        if (!isLimit) {
            memo[i][cnt1] = res; // 记忆化
        }
        return res;
    }
}
```

```go [sol-Go]
func countDigitOne(n int) int {
    s := strconv.Itoa(n)
    m := len(s)
    memo := make([][]int, m)
    for i := range memo {
        memo[i] = make([]int, m)
        for j := range memo[i] {
            memo[i][j] = -1 // -1 表示没有计算过
        }
    }

    var dfs func(int, int, bool) int
    dfs = func(i, cnt1 int, isLimit bool) (res int) {
        if i == m {
            return cnt1
        }
        if !isLimit {
            p := &memo[i][cnt1]
            if *p >= 0 { // 之前计算过
                return *p
            }
            defer func() { *p = res }() // 记忆化
        }

        up := 9
        if isLimit {
            up = int(s[i] - '0')
        }

        for d := range up + 1 { // 枚举要填入的数字 d
            c := cnt1
            if d == 1 {
                c++
            }
            res += dfs(i+1, c, isLimit && d == up)
        }
        return
    }

    return dfs(0, 0, true)
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(Dm^2)$，其中 $m=\mathcal{O}(\log n)$，$D=10$。由于每个状态只会计算一次，动态规划的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题 $i$ 和 $\textit{cnt}_1$ 都有 $\mathcal{O}(m)$ 个，所以状态个数为 $\mathcal{O}(m^2)$，单个状态的计算时间为 $\mathcal{O}(D)$，所以动态规划的时间复杂度为 $\mathcal{O}(Dm^2)$。
- 空间复杂度：$\mathcal{O}(m^2)$。即状态个数。

### 写法二：贡献法

去掉 $\textit{dfs}$ 中的 $\textit{cnt}_1$ 参数，写在返回值中。也就是**自底向上**计算所有 $\textit{cnt}_1$ 的总和 $\textit{sum}$。

回想一下如何统计一棵二叉树的节点个数：

- 递归左子树，拿到左子树的节点个数 $\textit{leftSize}$。
- 递归右子树，拿到右子树的节点个数 $\textit{rightSize}$。
- 加上当前节点（$1$ 个），得到当前子树的节点个数 $\textit{leftSize} + \textit{rightSize} + 1$。

本题如果只考虑每个数位怎么填，可以视作一棵**十叉树**。

统计 $1$ 的总出现次数 $\textit{sum}$：

- 递归子树，累加子树中产生的 $1$ 的出现次数，加到 $\textit{sum}$ 中。
- 对于当前数位 $i$，如果填 $1$，那么这个 $1$ 会对后面所有剩余数位的填法都**贡献**一次。比如剩余数位有 $42$ 种填法，那么这 $42$ 个数都在 $i$ 处有 $1$，所以 $\textit{sum}$ 增加 $42$。

从上面的讨论中，我们还需要知道剩余数位有多少种填法，**每种填法都对应着十叉树的一个叶子**。虽然本题数位可以随便填，没有特殊的约束，但为了代码的可扩展性，我把剩余数位的合法填法也作为返回值。

也就是说，$\textit{dfs}$ 返回两个数，第一个数是剩余数位有多少种合法填法，第二个数是 $\textit{sum}$。剩余数位有多少种合法填法怎么算？这与统计十叉树的**叶子**个数的计算方式是一样的。

```py [sol-Python3]
class Solution:
    def countDigitOne(self, n: int) -> int:
        s = list(map(int, str(n)))  # 避免在 dfs 中频繁调用 int()

        # dfs 返回两个数：合法数字个数，1 的总数
        @cache  # 缓存装饰器，避免重复计算 dfs 的结果（一行代码实现记忆化）
        def dfs(i: int, is_limit: bool) -> Tuple[int, int]:
            if i == len(s):
                return 1, 0  # 本题无特殊约束，能递归到终点的都是合法数字

            up = s[i] if is_limit else 9
            cnt = sum_ = 0
            for d in range(up + 1):  # 枚举要填入的数字 d
                sub_cnt, sub_sum = dfs(i + 1, is_limit and d == up)
                cnt += sub_cnt  # 累加子树的合法数字个数
                sum_ += sub_sum  # 累加子树的 1 的总数
                if d == 1:  # 当前位置填 1
                    sum_ += sub_cnt  # 这个 1 会出现在 sub_cnt 个数字中

            return cnt, sum_

        return dfs(0, True)[1]
```

```java [sol-Java]
class Solution {
    public int countDigitOne(int n) {
        char[] s = Integer.toString(n).toCharArray();
        int[][] memo = new int[s.length][];
        return dfs(0, true, s, memo)[1];
    }

    // dfs 返回两个数：合法数字个数，1 的总数
    private int[] dfs(int i, boolean isLimit, char[] s, int[][] memo) {
        if (i == s.length) {
            return new int[]{1, 0};
        }
        if (!isLimit && memo[i] != null) { // 之前计算过
            return memo[i];
        }

        int up = isLimit ? s[i] - '0' : 9;
        int cnt = 0;
        int sum = 0;
        for (int d = 0; d <= up; d++) { // 枚举要填入的数字 d
            int[] sub = dfs(i + 1, isLimit && d == up, s, memo);
            cnt += sub[0]; // 累加子树的合法数字个数
            sum += sub[1]; // 累加子树的 1 的总数
            if (d == 1) { // 当前位置填 1
                sum += sub[0]; // 这个 1 会出现在 sub[1] 个数字中
            }
        }

        int[] res = new int[]{cnt, sum};
        if (!isLimit) {
            memo[i] = res; // 记忆化
        }
        return res;
    }
}
```

```cpp [sol-C++]
class Solution {
public:
    int countDigitOne(int n) {
        string s = to_string(n);
        int m = s.size();
        vector<pair<int, int>> memo(m, {-1, -1}); // -1 表示没有计算过

        // dfs 返回两个数：合法数字个数，1 的总数
        auto dfs = [&](this auto&& dfs, int i, bool is_limit) -> pair<int, int> {
            if (i == m) {
                return {1, 0}; // 本题无特殊约束，能递归到终点的都是合法数字
            }
            if (!is_limit && memo[i].first >= 0) { // 之前计算过
                return memo[i];
            }

            int up = is_limit ? s[i] - '0' : 9;
            int cnt = 0, sum = 0;
            for (int d = 0; d <= up; d++) { // 枚举要填入的数字 d
                auto [sub_cnt, sub_sum] = dfs(i + 1, is_limit && d == up);
                cnt += sub_cnt; // 累加子树的合法数字个数
                sum += sub_sum; // 累加子树的 1 的总数
                if (d == 1) { // 当前位置填 1
                    sum += sub_cnt; // 这个 1 会出现在 sub_cnt 个数字中
                }
            }

            pair<int, int> res = {cnt, sum};
            if (!is_limit) {
                memo[i] = res;
            }
            return res;
        };

        return dfs(0, true).second;
    }
};
```

```go [sol-Go]
func countDigitOne(n int) int {
    s := strconv.Itoa(n)
    m := len(s)
    type pair struct{ cnt, sum int } // 合法数字个数，1 的总数
    memo := make([]pair, m)
    for i := range memo {
        memo[i].cnt = -1
    }

    var dfs func(int, bool) pair
    dfs = func(i int, isLimit bool) (res pair) {
        if i == m {
            return pair{1, 0} // 本题无特殊约束，能递归到终点的都是合法数字
        }
        if !isLimit {
            p := &memo[i]
            if p.cnt >= 0 { // 之前计算过
                return *p
            }
            defer func() { *p = res }() // 记忆化
        }

        up := 9
        if isLimit {
            up = int(s[i] - '0')
        }

        for d := range up + 1 { // 枚举要填入的数字 d
            sub := dfs(i+1, isLimit && d == up)
            res.cnt += sub.cnt // 累加子树的合法数字个数
            res.sum += sub.sum // 累加子树的 1 的总数
            if d == 1 { // 当前位置填 1
                res.sum += sub.cnt // 这个 1 会出现在 sub.cnt 个数字中
            }
        }
        return
    }

    return dfs(0, true).sum
}
```

#### 复杂度分析

- 时间复杂度：$\mathcal{O}(Dm)$，其中 $m=\mathcal{O}(\log n)$，$D=10$。由于每个状态只会计算一次，动态规划的时间复杂度 $=$ 状态个数 $\times$ 单个状态的计算时间。本题状态个数等于 $\mathcal{O}(m)$，单个状态的计算时间为 $\mathcal{O}(D)$，所以总的时间复杂度为 $\mathcal{O}(Dm)$。
- 空间复杂度：$\mathcal{O}(m)$。即状态个数。

## 方法二：贡献法 + 数学公式

如果暴力枚举 $[1,n]$ 中的整数 $x$，计算 $x$ 中的 $1$ 的个数，就太慢了。

**横看成岭侧成峰**，对于 $[1,n]$ 中的整数：

- 在个位中，一共出现了多少个 $1$？（个位数字为 $1$ 的整数有多少个？）
- 在十位中，一共出现了多少个 $1$？（十位数字为 $1$ 的整数有多少个？）
- 在百位中，一共出现了多少个 $1$？（百位数字为 $1$ 的整数有多少个？）
- ……

把整数 $x$ 拆分成三段：

$$
\textit{prefix}\ | \ m\ |\ \textit{suffix}
$$

设 $n$ 的十进制长度为 $k$。枚举 $\textit{suffix}$ 的长度 $i=0,1,2,\ldots,k-1$。对于一个固定的 $i$，有多少个整数可以让 $m = 1$？

定义：

- $\textit{prefix}$ 的最大值为 $\textit{maxPrefix} = \left\lfloor\dfrac{n}{10^{i+1}}\right\rfloor$。
- 在 $\textit{prefix} = \textit{maxPrefix}$ 的情况下，$m$ 的最大值为 $M = \left\lfloor\dfrac{n}{10^i}\right\rfloor\bmod 10$。
- 在 $\textit{prefix} = \textit{maxPrefix}$ 且 $m = M$ 的情况下，$\textit{suffix}$ 的最大值为 $\textit{maxSuffix} = n\bmod 10^i$。

### 情况一

$\textit{prefix} < \textit{maxPrefix}$。此时低位可以随便填。

- $\textit{prefix}$ 从 $0$ 到 $\textit{maxPrefix}-1$，有 $\textit{maxPrefix}$ 个。
- $m$ 填 $1$。
- $\textit{suffix}$ 可以随便填，从 $0$ 到 $10^i-1$，有 $10^i$ 个。

根据乘法原理，**情况一对答案的贡献**为

$$
\textit{maxPrefix}\cdot 10^i
$$

例如 $n=23456$，万位千位可以是 $00,01,02,\ldots,21,22$，百位填 $1$，十位个位可以是 $00,01,02,\ldots,98,99$，所以此时百位上是 $1$ 有 $23\times 100 = 2300$ 种方案，加到答案中。

### 情况二

$\textit{prefix} = \textit{maxPrefix}$ 且 $M > 1$。

$m$ 填 $1$ 后，$\textit{suffix}$ 可以随便填，从 $0$ 到 $10^i-1$，有 $10^i$ 个。

所以**情况二对答案的贡献**为

$$
10^i
$$

### 情况三

$\textit{prefix} = \textit{maxPrefix}$ 且 $M = 1$。

$m$ 填 $1$ 后，$\textit{suffix}$ 可以填 $0$ 到 $\textit{maxSuffix}$，有 $\textit{maxSuffix}+1$ 个。

所以**情况三对答案的贡献**为

$$
\textit{maxSuffix}+1
$$

### 情况四

$\textit{prefix} = \textit{maxPrefix}$ 且 $M = 0$。

$m$ 只能填 $0$，无法填 $1$，贡献为 $0$。

综上，枚举 $i=0,1,2,\ldots,k-1$，累加贡献，即为答案。

```py [sol-Python3]
class Solution:
    def countDigitOne(self, n: int) -> int:
        ans = 0
        pow10 = 1

        while pow10 <= n:
            max_prefix = n // (pow10 * 10)
            M = n // pow10 % 10

            # 1. prefix < max_prefix 时，低位不受约束
            # m 填 1，suffix 随便填
            ans += max_prefix * pow10

            if M > 1:
                # 2. prefix = max_prefix 且 M > 1
                # m 填 1，suffix 随便填
                ans += pow10
            elif M == 1:
                # 3. prefix = max_prefix 且 M = 1
                # m 填 1，suffix 可以填 [0, max_suffix] 中的任意整数
                max_suffix = n % pow10
                ans += max_suffix + 1

            pow10 *= 10

        return ans
```

```java [sol-Java]
class Solution {
    public int countDigitOne(int n) {
        int ans = 0;
        // 注：pow10 *= 10 只在 n = 1e9 的情况下会溢出，由于溢出后的值仍然大于 n，所以 pow10 的类型不需要定义成 long
        for (int pow10 = 1; pow10 <= n; pow10 *= 10) {
            int maxPrefix = n / (pow10 * 10);
            int M = n / pow10 % 10;

            // m 填 1，suffix 随便填

                // m 填 1，suffix 可以填 [0, maxSuffix] 中的任意整数
                int maxSuffix = n % pow10;
                ans += maxSuffix + 1;
            }
        }
        return ans;
    }
}
```
